# Ridge U4-3 큰 배치 저작본 V003

사용자가 U4-2 V002를 확정하고 다음 단위를 승인했다. V003은 채택된 V002 맵을 복제하고 메사 북동쪽 절벽과 동쪽 상단 암괴만 추가한 채택본이다. 사용자 U4-3 확정(2026-11-24)으로 이 폴더와 맵을 동결하며, U4-4는 새 세션의 V004에서 진행한다. V037/V010 및 V001·V002 맵/저작 파일은 보존한다.

- `RidgeLayout.json`: 기존 기준 해시, 채택 V002 맵과 이전 저작 파일 해시, Z2 세 소유자의 고정 자세/참조/지문, 구역 JSON과 근거 폴더를 연결한다.
- `EDTerrainLayout_Z2.json`: 채택된 세 소유자를 담는 V003 전용 사본이다. export가 이전 V002 JSON을 덮어쓰지 않게 분리했다.
- `EDTerrainLayout_Z4.json`: 새 두 소유자의 자세·원본/사본 해시, 보호 공간과 몸체 인계를 소유한다. 02c 절벽은 로컬 `(−1800,−10000,H−700)`·yaw80°, 01b 상단 암괴는 `(−2600,−11800,H1000)`·yaw25°, 모두 원래 크기1이다.
- 새 조립체 사본은 `U4Layout_V003/Z4Assembly_V003/`에 있다. 원본의 내부 배치와 크기, 공유 메시/재질/BPP는 수정하지 않았다. 같은 조립체를 긴 벽으로 반복하지 않고 동쪽 강조부를 잡았다. 서쪽 기준은 기존 U4-2 받침이다.

`RidgeLargeLayout.py export V003`은 기존 Z1·채택된 Z2 세 소유자 보존, 전체 dirty 없음, 20개 하위 레벨 로드, 신규 NoCollision·인스턴스 수를 대조한다. 신규 Z4는 하류·중상류·석교 갑판·협곡 Pod·동굴 접근·MesaAscent·SouthMesa Pod·석교 남단 접근의 여덟 보호 공간을 검사한다. 통과해야 실제 자세를 V003 구역 JSON에 되읽는다. 사용자 실행 `Export_20261124_221922_034419.json`은 PASS/export 완료다. 기존 Z1·채택 Z2 세 배치·보존51파일 불변, 신규8,723+505인스턴스 NoCollision·여덟 보호 공간 겹침0이며 실제 자세를 기록했다. 경고1건은 기존 북벽 AttachTo다. 새 구도는 사용자가 채택했다.

기존 덤프를 새 자세로 옮긴 사전 좌표 대조에서는 두 후보 모두 여덟 공간의 겹침0이었다. 메시 로컬 상자에50cm 여유, 경로2m 간격3열, Pod 반경9m와+1~61m의13층을 사용한다. 이는 시각 배치의 보수적 표본 검사이며 충돌·PIE 통과가 아니다.

근거는 `Saved/Profiling/Graphics/Phase01/U4_3_V003/`다. `PreviousAccepted/`는 채택 V002의4파일 복구 사본, `CandidateSurvey*.json`은 읽기 전용 사전 대조, `ReviewCameras.json`·`Views_Draft/`·`CaptureMetadata_Draft.json`은 실제20개 로드 후 비교12시점이다.

새 환경에서 필요한 입력이 모두 있고 결과 맵이 없을 때만 `build V003`으로 채택 V002를 복제하고 신규 소유자만 추가할 수 있다. 기존 생성물을 준비 목적으로 재실행하지 않는다. 동일 이름이 있으면 중단한다.

몸체·충돌·SurfaceData·기반면 재빌드와 연속 외피·잔돌·식생 마감은 후속이다. 현재 충돌/마커는 V010 보존 상태다. 다음 U4-4 메사 오름길/남쪽 외곽은 새 세션에서 시작하고 단위 완료 뒤 다음 진행을 확인한다. 인계 원본은 `.context/Graphics/analysis/Phase01_U4LayoutHandoff.md`다.

# Ridge U5a-0 내부 몸체 시험 입력

채택 U4Layout_V011의 추가21소유자 자세/참조/지문과 저작8파일·이전 저작53파일, 기존 Z1 기준을 고정한다. 실제 export PASS와 사용자 채택을 확인했다. 이 단위는 입력 조사이며 몸체/충돌 생성과 새 UE 시험 맵은 아직 만들지 않았다.

- 외곽 추가 장식은 종료한다(GX-036). 삼각형 안쪽 보라 구조물과 부유섬2개는 후속 장식 대상이다.
- 첫 시험은 R01/R05 열린 세로 외피와 R03/R04 같은 하부 공동의 두 입구를 함께 포함한다. R02/R06도 회귀 감시한다.
- 의도된 동굴2·석교·부유섬2, 기존51개 보호 공간을 유지한다. 내부 보라색 전체를 몸체로 메우지 않는다.
- 기존 Cull 이전 덤프와 당시 제외 결정을 읽기 전용으로 대조해185,555개 잔존 인스턴스를 재구성했다. 생성기를 재실행하거나 제외 인스턴스를 복원하지 않았다. 메시 상자 후보는 노출 면이나 실제 몸체 경계의 확정이 아니다.
- 생성법·해상도·맞춤 수치는 아직 선택하지 않았다. 기존40cm 판 두께를 닫힌 몸체의 해결책으로 재사용하지 않는다.
- 다음 생성 결과는 전용 U5aBody_V001 맵/에셋으로 시험한다. 시각/충돌 공통 몸체와 내부 지각/Support 제거·Floor50㎡·전체 Nav Layer256·구면 Up·seam 계약을 확인한다.
- 실제 접근 검증은 필요한 범위를 사용자 수동 PIE로 요청하며, 전체 베이크/PIE와 식생·잔돌 마감은 후속이다.

## 현재 생성 시험(U5a-1)

현재 기준은 `Generation_V002.json`이며 U5aBody_V002/생성V006의4메시·96,344삼각형을 NoCollision으로 반입·검사했다. 기존 Z1/채택21개/156파일 보존 PASS, 닫힌 형상 검사 PASS, 경사로32표본 겹침으로 REVIEW·미채택이다. `BodyTrial.json`의 generation_not_started는 U5a-0 입력 고정 당시 스냅샷이며 현재 진행 상태를 뜻하지 않는다.

- Blender: `BuildRidgeClosedBodyTrial.py -- build V006`, 이어 `check V006`·`fit V006`·`profile V006`. 이미 만든 버전에 build를 재실행하지 않는다.
- UE: 새 사본을 연 뒤 `RidgeClosedBodyTrial.py import V002`가 새4메시 반입·지정 저장·보존 검사를 자동 실행한다. 이미 반입했으므로 다시 import하지 않는다. `verify V002`는 읽기 전용이다.
- 기존 생성기/원본/공유 에셋은 재실행·수정하지 않았다. 초기V004 메시/맵도 보존했다. UV 탄젠트/바이노멀 경고는 V006에서 해소됐다.
- 다음은 몸체 경계/외관 다듬기·StairRamp3 별도 연결 검토다. 충돌·내부 지각/Support·전체 베이크/PIE·다른 구역 확대는 후속이다. 비교/실제 검사 근거는 `Saved/Profiling/Graphics/Phase01/U5a_1_V002/`와 `.context/Graphics/analysis/Phase01_U5aBodyTrial.md`를 따른다.

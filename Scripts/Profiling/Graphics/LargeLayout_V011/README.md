## 외곽 종료와 내부 우선(GX-036)

사용자가 현재 외곽 배치 정도에서 추가 장식을 종료했다. 외곽 보라 전이 띠는 더 채우지 않는다. 삼각형 안쪽 보라색과 두 부유섬은 장식 대상이며, 의도된 동굴/석교/부유섬 형상을 보존하는 별도 단계로 진행한다. 기존 큰 배치 안쪽의 닫힌 몸체 시험을 먼저 하고 세부 식생·잔돌 마감은 후속으로 둔다.

# Grove V002 공간 구상도

이후 사용자가 방향과 거목 100~170m를 긍정 평가하고 열린 경계·낮아진 공터/분지·지하/가지 Pod·로우폴리를 추가 지시했다. 이미지의 세 진입 화살표는 유일한 입구가 아니며 긴 외곽 거목벽은 구현하지 않는다. 실제 제작본은 [V005](../V005.md)를 따른다. 아래 생성 이미지 자체는 수정하지 않았다.

2026-11-09 사용자 요청으로 실제 재제작 전에 탑뷰와 사이드뷰를 생성했다. 현재는 검토용 제안이며 채택된 치수나 구현본이 아니다. V001 에셋·에디터·풀은 변경하지 않았다.

- `V002_TopView.png`: 거목 7개·공터 5곳·세 경계 진입·지상 순환 A→B→D→C→E→A와 중앙 횡단 A→C·동쪽 회복 분지. 점선은 T1/T2/T4와 공터 A/B의 대표 제작 범위다.
- `V002_SideView.png`: 동서 방향에서 A–A′ 인근 구조물을 함께 투영한 측면 구상. 플레이어 1.9m와 Pod 2.5m를 거목에 대비하고 뿌리 위 선택 경로·지상 주 동선·분지 복귀를 구분한다.
- 시작 치수 가정: 줄기 굵기 35~60m·거목 높이 100~170m·공터 폭 45~70m·주 보행 폭 18~28m·뿌리 능선 높이 8~15m·회복 분지 깊이 6~10m.

구면 옥탄트를 펼친 개념도다. 생성 이미지의 윤곽·축척·높이 눈금은 실측 도면으로 사용하지 않으며, 공간 구상을 채택한 뒤 같은 배치를 실제 구면 좌표의 평면/단면과 형상으로 맞춘다. 수관 천장·부유섬·중앙 탑 상승은 넣지 않는다. Pod 표시는 후보 공간이며 전역 총량 변경을 뜻하지 않는다.

내장 `image_gen`으로 생성했으며 탑뷰를 사이드뷰의 배치·화풍 참고 이미지로 사용했다. 전체 생성 프롬프트는 `V002_Prompts.json`에 보존한다.

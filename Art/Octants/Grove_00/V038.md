# Grove V038 큰 지하 공동

2026-11-09. 사용자가 V029 지상·공중 공간을 확정하고, 지하는 비행 드론이 배치 가능한 크기로 더 넓고 깊게 만든 뒤 소량의 기둥/바위 엄폐물을 요청했다. 지상·상부의 나무/뿌리/공터/가지·정상/경사/훅 저작값과 경로는 고정 비교하며 지하만 확장했다.

## 크기와 출입

| 공간 | 최종 구성 |
|:---|:---|
| 큰 공동 | 저작 반경55m, 구면 투영 뒤 두 축 직경 약133/138m. 바닥 H=-100m, 중앙 높이50m·가장자리 약30m |
| Central | 굽은 우회 경사로. 저작 길이 약300m, 투영된 보행 중심선 약365m. 기존 밑동 입구에서 공동으로 양방향 보행 |
| West | 수직 구멍·H=-55m 중간 착지턱·H=-88m 바닥·우회 연결 통로. 바닥→공동 중심선 약112m |
| North | 수직 구멍·같은 높이의 착지턱/바닥·완만한 지하 연결로. 바닥→공동 중심선 약156m |
| 엄폐 | 천장에 닿는 기둥2개, 낮은 바위3개. 중앙 비행 띠와 공동 둘레 보행 띠를 비움 |

H는 지각 기준 구 중심 쪽 높이다. 현지 지면과 공동 바닥의 차이는 약80~90m다. 두 수직 출입 바닥은 복제 위치 int16 cap을 지키기 위해 H=-88m에 두고, 평탄 착지 공간 뒤에서 큰 공동으로 내려간다. 중앙 공동의 깊이/높이를 줄이거나 전역 좌표/중력 설정을 바꾸지 않았다.

지각부터 공동 바닥 밑까지 단일 외피를 만들고 연결된 void를 뺀다. 기둥/바위/수직 착지턱은 굴착에서 제외해 같은 소유자로 남긴다. 기존 지각 면을 해당 작업 구역에서 교체하며 같은 자리에 옛 지하를 덧붙이지 않는다. 평탄부와 내리막의 전환 단면은 CDT 제약선으로 만든다.

원본은 `Grove_00_V038.blend`, spec `Scripts/GroveRootNetworkSpec.py`, 형상/검사는 `BuildGroveRootNetwork.py`·`VerifyGroveRootNetwork.py`다. 반입은 `AssembleGroveOctant.py`, 베이크/드론 후보 확인은 `BakeGroveOctant.py`, 실제 충돌은 `VerifyGroveReady.py`다. 작업 에셋 `/Game/Maps/_WorkInProgress/Grove_00/V038/`, 보고서/FBX/로그 `Saved/SliceOctant/Grove_00/V038/`, 코드 사본 `SourceAtReview/`다. 승인된 V029 원본/에셋과 코드 사본은 보존한다.

## 드론과 검증 범위

현재 `DA_Enemy_PureEntity_Flyer01`은 FreeFlight, 배회 고도13~23m, 몸 반경/반높이80cm, 추가 충돌 여유50cm다. `GetSpawnRequiredHeadroom()`은 배회 상한+몸80+여유50+고정200cm를 사용하므로 현재 필요 headroom은2630cm다.

- 새 지하 Pod의 베이크 headroom은5002cm다. 현재 설정의 Pod 적 반경15m 안에 같은 Layer·Enemy 허용·필요 headroom을 만족하는 후보42개를 확인했다. `cavern-drone-bake.json`이 실제 설정/후보를 기록한다.

서쪽 착지·곡선 진입의 높이 오차와 두 수직 출입의 좌표 cap은 후보 검사에서 수정했다. 검사 허용 오차/엔진 cap을 늘리지 않았다. 상세 중간 후보 기록은 [확장 작업 기록](UndergroundExpansion.md)에 보존한다.

## 짧은 PIE 검토

서버 콘솔 `LNP.Debug.TeleportToReview <Name> 0`:

- `GroveUndergroundHub`: 공동 크기·천장·엄폐 간격과 둘레 순환.
- `GroveUndergroundCentral`: 긴 우회 경사로의 양방향 진입/복귀.
- `GroveUndergroundWest` / `GroveUndergroundNorth`: 구멍의 안쪽 진입턱에서 ShaftLedge 앵커로 중간 턱에 착지하고, ShaftBottom으로 바닥에 내려간다. 바닥에서는 ShaftLedge→ShaftReturn 순서로 지상 복귀한다.
- 각 수직 통로는 `...Lip` / `...Ledge` / `...Bottom` 접미사로 직접 검토할 수 있다.

적 밀도0 검토는 공간/착지 확인이며 실제 드론 추격·회피·사격 성공을 뜻하지 않는다. 새 공동의 게임 내 밝기와 카메라 가독성도 사용자 확인 대상이다. 지상·공중을 다시 전부 탐색하도록 요청하지 않는다. 지하 피드백 뒤 정식 경로 채택·결정론·실제 풀 등록·전체 SurfaceNavigation·혼합 PIE를 이어간다.

# Grove V041 그래플 앵커 통합·높이 조정

2026-11-10. 사용자 요청에 따라 V040 확정 지형을 유지하며 가까운 앵커를 통합하고 과도한 상부 여유를 줄였다. 앵커55→40개, 기존57개 접근은 유지한다. 작업 레벨은 `/Game/Maps/_WorkInProgress/Grove_00/V041/LVI_Octant_Grove_00`이며 지형 메시/재질은 V040 에셋을 참조한다. 새 지형 blend나 FBX는 생성하지 않았다.

## 배치 변화

같은 좌표의 상승/하강 앵커14쌍을 공유하고, 약6.9m 떨어진 T1/T4 지상 복귀 앵커도 통합했다. 공유된 앵커에 원래 접근 출발점을 모두 남겼다. 대부분의 가지 앵커는 기존35m 여유에서20~30m로 낮췄으며, 발판 옆면·출발 턱에 걸리는 곳은 높이를 일부 유지했다. 접근 쪽으로2~8m 옮긴 앵커도 있다. 모든 후보를 낮추기만 하지는 않았다. 최종40개 중37개 하향·2개 기존 높이·분지 복귀1개만1.5m 상향이다. 마지막 항목은 기존 낮은 앵커의 몸체 접근 여유를 보완한 것이다.

T1/T4 지상 복귀는 T1 기존 지상 착지 구역을 공유한다. 두 가지에서의 시야/몸체 접근·착지 띠를 확인했다. 남은 앵커의 최소 중심 간격은 약21.28m이며 T1LowerBranchArrival / T4LowerBranchArrival 쌍이다. 역할이 다른 지하 상승/하강 앵커는 보존한다.

## 검증과 보존

- 원본 전체 경로/공중/지하 검사 바닥9,547·여유8,921, 실패0. 현재57개 접근에서 시야·몸체5점 광선·150cm 전방 정지 후 수직 낙하·반경4m 착지 띠를 확인했다.
- 엔진에서는 앵커 변경 범위만 재검사했다. 착지 바닥456·시야/몸체/낙하 여유399개 일치·최대차이0.00266cm, 추가 조준 시야57·Pod 머리 공간72·앵커ID40/SpawnID8 확인. 광선 근사이며 캡슐 sweep·Mover 관성·입력 착지를 대신하지 않는다.
- 곡선 뿌리의 착지 기대 높이는 해당 뿌리 상면의 굴곡을 따라 계산한다. EastGround 출발은 이음매 지각의 실제 높이 약H=-922.75cm를 사용했다. 저작 검토점의 명목H=-1000cm와 실제 바닥의 차이를 보정한 검사이며 지형이나 검토점을 이동하지 않았다.
- V040 지형3개 에셋/원본blend 해시 불변. 레벨 사본에서 앵커 외135개 액터의 변환/GUID와 지형 참조를 비교했다. 조명41개·Pod8개 보존이다. 재시작 후에도 저장된40개 마커의 위치/사거리와 지형/조명/Pod를 다시 확인했다.
- V041 레벨 사본에 맞춰 베이크했다. Support59 Layers/1,921,443 samples, Nav128,907 cells/83 components/423 portals, Traversal1,530, Spawn authored8/random11,871. 스트림별 요소 수/크기는 V040과 같고 콘텐츠 경고0·Meadow seam2,208 일치다. 원시 payload의 바이트 동일성을 별도로 단정하지 않는다.

- 기존327개 파일·실제 풀/DefaultGame.ini·다른 Graphics 작업을 보존한다. C++/Live Coding/전체 빌드와 전역 그래플 설정 변경은 사용하지 않았다.

## 이번 PIE 검토

적 밀도0의 V041 단독 검토 풀을 사용한다. 서버 콘솔 `LNP.Debug.TeleportToReview <Name> 0`:

- `GroveT1Ascent`: 낮은 가지→높은 가지→정상, 같은 공유 앵커로 하강·지상 복귀. T1/T4 지상 복귀 공유도 확인한다.
- `GroveT6Ascent`: 낮춘 앵커와 접근 쪽으로 옮긴 앵커의 착지/복귀.
- `GroveUndergroundWest`: 중간 턱→바닥→중간 턱→지상 복귀. North도 같은 방식이다.

조준 선택·접근 중 걸림·중도 해제/잔여 관성·착지 후 보행을 사용자에게 확인한다. 지형은 고정하며 실제 NPC 교전과 정식 풀 통합/전체 SurfaceNavigation/혼합 PIE는 후속 단계다.

# Pyramid_00 — 실내전 피라미드 폐허

## 현재 버전 V058 — 외벽·발판·층간 훅 동선 보강

2026-10-16. 승인된 V057의 방·복도·계단과 입체 파손부를 기준으로 외벽 파손 3곳과 외부 발판 6곳을 추가했다. 기존 입체 파손과 내부 구조에 불필요한 큰 관통을 만들지 않도록 새 파손은 불규칙한 얕은 외벽 절단이다. 각 파손의 두 높이에 폭 약 18m·외부 깊이 약 12.5m의 발판을 붙였다. 외벽 안쪽의 남은 바닥에서 발판 끝까지 보행 경로를 검사했다. 본체의 경계 좌표 최솟값은 2,972.5cm로 이음매 보호 영역을 지킨다.

파손부 훅 32개는 각각 독립 배치하던 방식에서 **같은 파손부 안의 층간 연결을 함께 고르는 방식**으로 바꿨다. 인접 중간 층의 상승·하강을 모두 검사하고 최하층을 제외한 연결 그래프가 양방향으로 이어지는지 확인한다. 상대 4층→2층 직접 하강을 포함해 가능한 여러 층 건너뛰기 경로도 기록한다. 모든 층 조합의 직통 이동을 요구하지는 않는다. 착지점에서 짧게 걸어 가장자리를 조준하는 출발도 허용하며, 이 보행 바닥·여유·앵커끼리 시야·접근선 주변 100cm 표본·도착 바닥 반경 250cm를 각각 확인한다. 좁은 상부 파손부에는 본체와 결합한 착지 발판 4곳과 필요한 벽의 사선 개방을 추가했다.

복층 홀 **26곳마다 상층 진입 훅을 하나씩** 추가했다. 최상층의 두 홀은 위에 완전한 다음 층이 없으므로 H126m에 부분 중층 착지대를 만들었다. 파손부 32개·복층 홀 26개·기존 Pod 전투 훅 23개로 총 **81개**다. 전역 훅 설정은 유지하고 필요한 사거리는 마커별로 정한다. 원본 경로 108개가 통과했으며 실제 훅의 당김·해제·관성 착지·타깃 선택은 사용자 PIE 검토 대상이다.

원본은 242,374 triangles다. 본체의 열린 변·비다양체·역방향 접합·중복 면·퇴화 면은 모두 0개다. 기존 계단 756개·이동패널 공간 4,545개 표본이 통과했고, 패널 Up 오차 최댓값은 0.1252° 이하다. UE 반입과 native 충돌에서 훅 착지 522개·접근선 540개·출발 보행 바닥 4,860개·외부 발판 보행 바닥 1,134개 표본을 통과했다. Pod 23개·이동패널 5개를 유지한다. 최종 베이크의 Support는 191 Layers·100,063,821 bytes로 V057보다 1,042,122 bytes(약 1.05%) 늘었고 Navigation은 6,114,448 bytes다. Meadow 경계 표본 2,208개가 일치한다. 혼합 정의·스폰 편성·중력 회전·현재성/두 번 재베이크 재현성 자동 검사 **4개가 오류·경고 없이 통과**했다. 저장 stream과 두 재베이크 결과가 바이트 단위로 일치하며 production 풀 SHA256는 유지됐다. 최종 에셋 의존 패키지 25개에 작업 폴더 참조가 없고, 미참조 V057 리다이렉터 15개를 `Saved/SliceOctant/Pyramid_00/V058/RetiredRedirectors`에 해시와 함께 복구 보관했다.

TestMap03 PIE 초기 구동에서 Pyramid가 slot 2·7에 배치되고 8개 validated slot·경계 반경 차이 0을 확인했다(`Saved/SliceOctant/Pyramid_00/V058/PIESmoke.log`). 초기 확인 뒤 PIE를 종료했다. V057에서도 발생했던 플레이어 Mass의 `CharacterMovementComponent` 추출 오류는 1회 기록됐으며 별도 범위다. 이 초기 구동은 실제 훅 이동 성공을 뜻하지 않는다.

사용자가 2026-10-16 V058의 공간과 동선을 승인하여 이 버전으로 제작을 확정했다. 새 피드백이 있기 전에는 훅·Pod 위치를 다시 탐색하지 않는다.

## 최종 원본과 재현

- `Pyramid_00_V058.blend`: 확정 형상·역할 메시와 편집 가능한 건물/파손 설계 원본. 외부 구버전 파일에 의존하지 않는다.
- `Pyramid_00_V058_Manifest.json`, `Placement.json`: 최종 역할·치수·원본 SHA256와 native 확정 마커 배치.
- `Pyramid_00_V058_GeometryProof.json`, `Pyramid_00_V058_RouteProof.json`, `Pyramid_00_V058_FacadeProof.json`: 확정 형상의 공간·층간 연결·발판 검사 기록.
- `Scripts/Blender/ExportPyramidOctant.py`: 최종 `.blend`의 SHA256·토폴로지·역할별 삼각형 수/bounds를 확인하고 `Saved/SliceOctant/Pyramid_00/V058`에 FBX와 조립 입력을 복원한다. 확정 배치를 변경하지 않는다.
- `Scripts/Blender/PyramidOctantCommon.py`: 출력·검사 공통 좌표 함수. `VerifyPyramidOctant.py`와 `PlacePyramidRuptureAnchors.py`는 새 버전 제작 때 쓰는 공간 검사/배치 도구다. native 확정 배치의 원본 재탐색은 차단한다.
- 재현 순서는 Blender background에서 Export → 에디터 종료 → `Scripts/RunPyramidValidation.ps1 -Assemble`이다. 후자는 반입·native 충돌·최종 베이크·자동 검사를 실행한다. 저장된 에셋 검사만 반복할 때는 `-Assemble`을 생략한다.
- 새 형상 제작에서는 버전을 올리고 원본·배치·검사 기록을 함께 갱신한다. 기존 SHA256를 수정해 검사 기록을 그대로 재사용하지 않는다.

## 사용자 검토 기록과 시작점

[층별 평면도](FloorSections.svg)는 파란 점이 Pod, 자주색 점이 파손부 훅, 초록 점이 복층 홀 훅이다. 마지막 행은 최상부 부분 중층이다. 검토 시작점은 `LNP.Debug.TeleportToReview PyramidCrypt`, `PyramidEntry`, `PyramidCrown`이며, 이번에는 중간 층에서 바로 위·아래층으로 이동하고 4층→2층으로 하강하는 동작을 우선 확인한다.

변경 동선만 빠르게 검토할 때는 `LNP.Debug.TeleportToReview PyramidCrypt` 후 `LNP.Debug.WhereAmI`로 현재 Pyramid slot을 확인한다. 아래 `<slot>`을 그 번호로 바꾼다. 층 번호는 8번 파손부 안에서의 상대 층이다.

| 확인 동작 | 서버 콘솔 시작점 | 확인할 내용 |
|:---|:---|:---|
| 8번 파손부 2층→3층 | `LNP.Debug.TeleportToOctant <slot> -5435 5680 -4200` | 가장자리로 조금 이동해 위 훅 조준·당기기·해제 착지 |
| 같은 파손부 4층→2층 | `LNP.Debug.TeleportToOctant <slot> -4812 7438 -1400` | X−4916/Y7268 쪽으로 약 2m 걸어 아래 훅 조준·직접 하강 |
| 지상 복층 홀→상층 | `LNP.Debug.TeleportToOctant <slot> -11117 -8516 0` | Hall_4_0의 상층 훅으로 올라가 바닥에 착지 |

위 좌표는 검사된 실제 바닥 위치다. 텔레포트 명령이 높이 150cm를 추가한다. 조준 카메라·타깃 선택·관성 착지 성공을 자동 통과로 기록하지 않는다.


## 확정 공간 구성

반지름 300m 옥탄트의 곡면에 맞춘 삼각쌍뿔이다. 파라미터 지상 높이 180m·지하 깊이 90m이며 외벽이 고도에 따라 좁아진다. 일반 층고 14m·총 13층, 복층 홀 26곳이다. 홀 명목 높이는 28m·슬래브 제외 약 27.2m이고 실제 Pod 지점에서 드론 스폰 여유 26.3m를 확인한다.

층별 용도는 지하 수장고·정비 작업장·훈련장·하역 통로, 지상 로비·전시장·회의장·사무실·강당·연구실·임원실·식당·최상부 포럼이다. 천장까지 이어진 벽과 기둥, 방·복도·승강기 코어·보행 경사로로 완성된 건물을 만든 후 입체 파손체 11개를 적용했다. 이후 V058에서 외벽 파손 3곳과 발판을 보강했다.

보행용 계단/에스컬레이터 경로 12개는 실제 충돌 경사로이며 투영 후 약 43.16°로 Mover 한계 약 44.77° 이내다. 디딤판이나 벨트 애니메이션은 없는 그레이박스다. 이동패널 5개는 실내 승강기 3개(12m)·외부 판 2개(24m)이며 경로 전체에서 현지 중력 수평을 보간한다. 보스 전투장은 실내 강당 구역이며 외부 랜드마크 식별성의 제약은 사용자가 허용했다.

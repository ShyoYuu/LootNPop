# 엘리트 NPC 기획 규칙

> 상태: 초안(사용자 확정 항목은 표시)
> 소유: 엘리트가 플레이어에게 어떻게 보이고 어떻게 공략되는가. 구현은 `Architecture.md`가 소유한다.
> 마지막 갱신: 2026-11-05

## 1. 엘리트의 자리

- 적 구성의 목표 그림은 "수백 마리 PureEntity가 달려드는 장면 + 소수의 엘리트"다. 전체 NPC의 90% 이상이 PureEntity다.
- 엘리트는 Pod와 무관하게 존재한다. Pod를 지키는 무리가 아니라 **월드의 위협(배회)** 또는 **옥탄트의 목적지(아레나)**다.
- 엘리트만 GAS·몽타주·랙돌을 쓰는 Actor로 싸운다. 고도의 전투 패턴은 엘리트만 갖는다.

| 종류 | 위치 | 플레이어에게 읽히는 의미 |
|:---|:---|:---|
| 배회 엘리트 | 월드 전체. Pod에서 일정 거리 이상 떨어진 곳에서 시작해 옥탄트를 넘나든다 | 마주치면 피하거나 싸울지 고르는 위협 |
| 아레나 엘리트 | 옥탄트마다 보스 무대로 설계한 랜드마크 안([Guide_OctantLevelDesign.md](../../Guide_OctantLevelDesign.md) §4.2) | 멀리서도 보이는 최종 목적지. 쓰러뜨리면 그 옥탄트의 정복으로 읽힌다 |

## 2. 교전과 이탈

### 2.1 아레나 엘리트 (사용자 확정 EL-006, EL-008)

- 평소에는 앵커 근처에서 대기한다(Guard). 아레나 밖으로 나가지 않는다.
- **플레이어가 아레나 안에 있을 때만 교전한다.** 서버 명중 판정 시 아레나 밖인 공격자의 피해·경직·넉백은 거부한다. 귀환·리셋 중인 보스도 피격되지 않는다(EL-015, §6.1).
- 플레이어가 아레나를 벗어나면 추격을 끊고 앵커로 돌아간다.
- 일반 교전에서 Confirmed 타겟 없이 `DisengageResetDelay`(초안 3초)가 지나면 **HP·경직·페이즈를 전부 초기값으로 되돌린다.** 슬롯 재조정으로 잠깐 타겟이 끊기는 정도로는 리셋되지 않는다. 귀환 중에는 §6.2의 앵커 도착 조건과 넉백 예외를 적용한다.
- 전투 이동은 아레나 반경 밖으로 나가지 않는다. 넉백으로 밀려 나가면 귀환한다.
- 귀환 목표는 타겟 주시·추격보다 우선한다. 앵커 도착까지 재교전을 보류하고, 플레이어 이탈 귀환은 완전 리셋한 뒤 재교전한다. 안에 유효한 플레이어가 계속 남은 넉백 귀환은 HP를 유지한다(EL-016, §6.2).

### 2.2 배회 엘리트

- 고정 앵커가 없다. 시야·인지 규칙으로 플레이어를 발견하고, 놓친 뒤 인내 시간이 지나면 다시 배회한다.
- Pod 적처럼 "세력권"이 없다. 끌고 다니는 것이 성립한다 — 배회 엘리트는 원래 쫓아오는 위협이다.
- 이탈 리셋은 없다(초안). 깎인 HP는 그대로 남는다. 들락날락하며 깎는 공략은 허용한다.

## 3. 사망과 재등장 (사용자 확정 EL-006)

- 엘리트는 **세션당 한 번만 등장한다.** 죽으면 그 세션에서는 다시 나오지 않는다.
- 죽으면 LootDice를 드랍한다. 드랍 후보와 개수는 적 타입마다 정한다(`DeathRewards`, 보상 세트는 Pod 보상과 같은 형식 — 후보 풀에서 MinDrops~MaxDrops회 가중 추첨, 중복 허용).
- 드랍 위치는 사망 지점이다. Dice 수명(60초) 규칙은 기존과 같다.

## 4. 전투 패턴 (초안)

- 엘리트 한 종은 패턴 4~6개를 갖는다. 패턴은 거리 대역, 정면각, 페이즈에 따라 고른다.
- 2페이즈 구성: HP 비율이 임계값(초안 50%) 아래로 내려가면 전환 연출 1회 → 패턴 풀과 가중치가 바뀐다. 현재 페이즈는 HP에서 파생하고 연출 소비 여부는 엔티티에 따로 남긴다. 연출 시작 시 소비하며 완전 리셋 때 다시 허용한다(EL-017, §6.3).
- 패턴은 기존 판정 규칙을 그대로 따른다. 근접은 패링·가드·저스트 회피가 성립하고, 투사체는 타입별 반사 규칙을 따른다.
- 경직은 기존 누적·그로기·다운 체계를 그대로 쓴다. 엘리트는 임계값을 높게 둬서 그로기가 "만들어 내는 딜 구간"이 되게 한다([GameDesign_Poise.md](../../GameDesign_Poise.md)).
- 타겟 전환(어그로)은 전투 두뇌가 아니라 기존 슬롯 타겟팅이 정한다. 2인 플레이에서 누구를 노리는지 규칙은 Pod 적과 같다.

## 6. 설계 검토 후 확정한 세부 규칙 (2026-11-05)

### 6.1 아레나 피격 자격 (EL-015)

- 서버 명중 판정 시 공격자가 아레나 안이고, 보스가 귀환·리셋 중이 아닐 때만 피해·경직·넉백을 허용한다. 안에서 발사한 뒤 밖으로 나가면 남은 탄도 피해를 주지 못한다. 발사 때 밖에 있었어도 명중 판정 때 안이면 이 위치 조건은 통과한다.
- 교전 중인 동료가 안에 있어도 밖의 공격자는 자격을 얻지 않는다. 발사체가 경계를 통과하는 사실과 공격자의 자격은 별개다. 추격 자격 제한과 지연 리셋만으로 바깥 공격을 막았다고 보지 않는다.
- 근접·직격·스플래시의 기술 기준은 Architecture §5.4가 소유한다.

### 6.2 귀환 완료와 재교전 (EL-016)

- 귀환 시작 후에는 앵커 도착까지 재교전을 보류한다. 플레이어 이탈로 귀환했다면 앵커 도착과 해제 지연을 모두 충족해 완전 리셋한 뒤 재교전한다. 플레이어가 도중에 재진입해도 이 귀환·리셋을 취소하지 않는다. 귀환 중에는 §6.1의 피격 차단을 적용한다.
- 넉백으로만 경계 밖에 밀렸고 아레나 안에 추격 가능한 플레이어가 남아 있다면 앵커 귀환 후 **HP를 유지하고 재교전**한다. 귀환 때문에 슬롯을 억제한 시간을 교전 해제로 세어 자동 회복시키지 않는다. 귀환 도중 플레이어가 전원 이탈하면 교전 해제 귀환으로 전환해 완전 리셋한다.
- 일시적인 슬롯 상실만으로 위 귀환 고정을 시작하지 않는다. 추격 가능한 후보가 남았는지와 슬롯을 실제 받았는지를 구분한다. 일반적인 슬롯 상실의 해제 리셋 지연은 EL-006의 기존 규칙을 유지한다.

### 6.3 전환 연출의 1회 소비 시점 (EL-017)

- 연출 GA 발동 성공으로 연출이 시작될 때 소비한다. 시작 전에 발동이 실패하면 미소비다. 시작 후 경직 등으로 중단되면 다시 재생하지 않고 해당 페이즈 패턴으로 진행한다.
- Arena 완전 리셋 때 다시 허용한다. 경직·재교전·Actor 재생성만으로 소비 이력을 지우지 않으며, Roam은 Actor 강등만으로 다시 허용하지 않는다.
- 현재 페이즈는 HP에서 파생하고 연출 소비 장부만 엔티티가 보존한다. 연출 중 사망하면 재시도하지 않는다.

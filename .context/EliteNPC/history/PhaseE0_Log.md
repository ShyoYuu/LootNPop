# E0 설계 검토 기록

## 2026-11-05 — 설계 검토 1~7 보강

- 사용자 요청으로 정적 검토의 1~7을 설계·계획·검증 문서에 반영했다. 구현과 PIE 검증은 수행하지 않았다.
- Architecture에 아레나 피격 자격, 귀환 목표 소유권, 위치+목적지 Surface 경로, 기존 내비게이션을 소비하는 전투 이동, 패턴 GA의 전체 수명·종료 계약, 엔티티 전환 연출 장부, 경직 GA를 포함한 리셋 정리와 사망 우선 규칙을 추가했다.
- 사용자 답변으로 EL-015~017을 확정했다. 명중 판정 시 위치로 바깥 공격 차단, 앵커 도착까지 귀환 유지, 안에 유효한 플레이어가 남은 넉백 귀환은 HP 유지, 연출 시작 시 소비·완전 리셋 때 재허용이다. 검토 중 제시한 공격 시작 위치 기준·바깥 피해 허용·즉시 재교전·연출 완료 시 소비 대안은 채택하지 않았다.
- 기존 EL-001~010은 유지하고 EL-011~014에 기술 보강의 결론을 추가했다. EL-016은 EL-006의 넉백 귀환 예외를 구체화하며, 현재 페이즈의 HP 파생(EL-007)과 연출 장부를 구분했다.
- E4·E5의 범위와 완료 조건을 보강했으므로 세션 수는 착수 전에 재산정한다. 다음 단계는 기존대로 E1이다. 사용자 결정 대기는 없다.
- 문서 검증: 8개 Markdown의 로컬 링크·코드 펜스 검사와 EliteNPC 범위의 `git diff --check`를 통과했다. 변경 diff와 확정 규칙 간 일관성을 점검하고 E4/E5 검증의 선행 의존성을 맞췄다. 검토 8번 이후 항목 전체를 해결했다고 기록하지 않는다.

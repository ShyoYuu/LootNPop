> 2026-10-10 최신 지시로 실행 계획을 [Hollow 전체 단순화 재제작](Phase09_HollowLowPolyRebuild.md)으로 전환했다. 아래는 이전 국소 재제작의 근거/기록이다. 정확한 기존 쉐입·폭 보존과구역별 PIE 순서는 새 계획의 제약이 아니다. 전체 재제작→생성·베이크·자동 검증→마지막 사용자 PIE 순서를 따른다. 동쪽 지각 국소 수정 후보의 수동Build 요청도 보류했다.

2026-10-10 갱신. 2026-10-08의 재제작안에서 출발했으며 사용자가 재제작 범위와 Blender 활용 판단을 맡겼다. 우선 목표는 이후 옥탄트에서도 재현할 설계·제작 절차다. 서쪽 대표 구역은V014에서 이전 갇힘/입구 가장자리 통행을 확인했고V015에서 보고된 세로 틈의 해소까지 사용자 확인을 받았다. 사용자 요청으로 남은 동쪽 Dock/Rim·외곽 구덩이 복귀·Shuttle 패널 우회를 이어간다. 동쪽V004는 반입·생성·베이크 후 능선 왕복 연결이 실패했다. V005도 시작부 곡률에서 연결이 실패해 상승 길이를25m로 늘린V006을 반입·Live Coding했다. 내부 보행 폭 전체565개 진단 침투0과 생성·베이크·정식2개 통과를 확인하고 사용자 PIE 검토를 요청했다. 실행 상태는 [Current](../Current.md), 측정 경위는 [Phase09_Log](../history/Phase09_Log.md)가 소유한다.

## 제작 방식 결정과 대표 시험

동쪽V006은 정식 검사 통과 뒤 사용자 PIE에서 실패했다. slot2/local(−10444,9248,H−428)의 작은 바닥 구멍과 벽 통과 후 Falling 지속/탈출 불가다. 넓은 밑동 윤곽 전체의 지각 제거를 실제 경사 부피 절단으로 고쳤다. 최종 외피와2,712곳 비교에서 절단 끝의 바깥 노출0/최소 매입3.626cm, Live Coding patch_5 Success다. Blender V006 에셋은 유지하고 실제 지각 재생성·조립 확인을 먼저 요청했다. 베이크·정식 검사·사용자 재검토 전이며 완료로 기록하지 않는다.

- 2026-10-10 재개: BackPocketV012의 편성 검사 실패·V013의 일방 통과 후 갇힘을 거쳐, V014의 구역 확장과V015의 단면 보정으로 보고 지점 통행/세로 틈을 사용자 확인했다. 구역 안 Generated 부분 제외와 내부 지각 절단은 구현·적용됐다. [V015 기록](Phase09_BackPocketV015.md)과 [동쪽 최신 기록](Phase09_EastRimV006.md)을 따른다.

- 코드에는 300m 지각/이음매·배치·Pod·앵커·장치를 남긴다. 복잡하게 이어지는 암반/경사/굴 접합은 Blender 원본에서 하나의 외피로 정리한다. 굽은 협곡 전체를 다시 만들기 전에 서쪽 BackPocket/절벽 부착 암반 구역 하나에 적용한다.
- 이후 동쪽 Dock/Rim을 같은 방식으로 재제작한다. 외곽 구덩이는 회복 가능한 진입 지형으로, Shuttle 주변은 패널 역할이 유지되는 간격으로 국소 재설계한다. 이미 사용자 확인한 비밀 통로 전체와 연속 훅을 다시 만들 필요는 없으며 접합 변경의 영향만 재검토한다.
- 한 구역의 형상 소유자를 코드 또는 Blender로 명시한다. Authored 임포트만으로 Generated가 사라지지 않으므로 교체 때 기존 생성 대상을 함께 제외한다. 서쪽 대표 구역에 부분 교체 코드를 적용했고 최종 조립 검증은 대기 중이다.
- `Scripts/Blender/BuildOctantWorkflowPilot.py`로 독립 V001을 제작했다. 원본 Boolean 몸체/경사/굴 cutter와 구면 출력 메시를 분리해 저장했다. Blender 5.2.0 LTS에서 2908 정점/5812 tris/덩어리 1, non-manifold·방향 불일치·중복·퇴화 0. 변 중점의 투영 오차 최대 0.166cm다. 자기 교차 검사는 미실시다.
- Floor 1438/Shell 4374를 `/Game/Maps/OctantWorkflow/V001`에 반입했다. UE 5.8에서 triangle 수 일치·bounds 최대 오차 0.0037cm·complex-as-simple/LOD0 확인·저장 성공. 원본/FBX/manifest/반입 결과/미리보기는 `Saved/OctantWorkflow/V001`이다. 현재 Hollow와 분리된 반입 시험편이며 실제 지형 품질 또는 비용 개선의 증거가 아니다.
- 기존 `GenerateSliceOctant.py`는 빈 spec도 전체 장면을 삭제했다. 빈/미등록 spec·기존 collection/이름에서는 변경 전에 중단하도록 수정하고, 생성은 소유 collection에 한정했다. 빈 spec·정상 메사 출력·반복 호출 차단에서 기존 객체 보존을 확인했다. Floor 분류 전 face index도 갱신한다.
- 공통 절차는 [설계 가이드](../../Guide_OctantLevelDesign.md)와 [제작 가이드](../../Guide_OctantLevelInstance.md)가 소유한다. 최종 조립 경계 전체·자동 캡슐·남은 보고 지점·정식 아트 에셋 시험은 남아 있다. 콘솔 실행은 제작 가이드 §6에 따라 사용자 수동 조작을 요청한다.

## 전환 이유

기존 LVI 재생성은 액터를 지우고 메시 에셋을 제자리 갱신하므로 이전 수리본이 계속 누적 배치되지는 않는다. 그러나 최근 spec에 추가한 채움 암반 4개와 기존 암반 경사로·메사·섬이 중첩돼 내부 면과 여러 Support 표면을 남겼다. `BuildCliff`의 채움 표면은 1m 이하로 분할한다. 높이 보간과 중심 경로 광선 검사만으로 외피 폐쇄·좁은 가장자리·탈출 가능성을 보장하지 못했다.

직전 베이크의 포털 검사 시간은 **173.124초**다. 포털 후보 781478/727946/474964, 간격 기각 472093개, Support sources 108/Layers 123, TotalSamples 2287854, 지각 236941 tris/부가 지형 193676 tris다. 메시 추출 2.98초·Layer raster 0.81초만 보고 베이크가 빠르다고 판단해서는 안 된다. 중첩 표면 제거 후 같은 베이크 옵션으로 전후 시간을 비교한다. 아직 재제작 결과의 시간 감소를 보장하지 않는다.

현재 본의 코드·정식 테스트·Hollow 에셋 224개를 `Saved/SliceOctant/Hollow_00/BeforeExteriorRebuild`에 보존했다. 이 경로는 로컬 복구본이며 Git에 넣지 않는다.

## 보존할 설계와 재제작 범위

- 월드 반지름 300m와 이음매 보존은 고정한다.
- 사용자가 채택한 굽은 협곡 실루엣·깊이·양쪽 절벽 높이, 절벽 잔도와 연속 훅, 중간 섬을 통한 정상 접근을 설계 기준으로 삼는다.
- 서쪽 왕복 길의 10m 보행 폭, 비밀 통로의 통행 폭·경로와 공동 두 수직 입구, 정상 아레나의 얇은 실루엣/완만한 지면을 유지한다.
- 서쪽·동쪽 외곽의 지각 접합/암반 몸체/경사/도착부를 서로 덧대는 닫힌 덩어리 대신 연속된 외피로 재제작한다. 겹치는 내부 면을 없애고 같은 접합 단면의 정점을 공유한다. 단순 Actor 합치기는 해결책이 아니다.
- 굴은 최종 암반 몸체에서 공간을 빼고 바닥·측벽·천장과 입구를 같은 경계로 접합한다. 내부로 일방 통과되는 면을 재료의 양면 렌더링으로 감추지 않는다.
- Rim 접안 굽이는 넓은 착지 공간으로 통합한다. 외곽 구덩이와 Shuttle 횡단 간격은 사용자 보고에 따라 국소 형상을 조정한다. Pod 8개와 기존 편성은 유지한다.

## 실행 순서와 검증 기준

1. 서쪽 굴 입구/왕복 암반, 동쪽 Dock/Rim, 외곽 구덩이의 실제 겹침 면·열린 경계를 확인한다. 대표 접합 하나에서 외피 통합 방식을 검증한 뒤 같은 방식으로 확장한다.
2. Floor·Shell을 합친 최종 외피의 중복 삼각형·열린 경계·면 방향을 검사한다. 서로 묻혀 있는 내부 바닥과 벽을 남기지 않는다. 필요한 곡률 정확도로 분할하며 임의의 1m 전면 세분화를 고집하지 않는다.
3. 플레이어 캡슐 반지름 42cm/반높이 96cm, 턱 오르기 40cm, 접지 한계 44.8°로 굽이 전체 폭·바닥/측벽/천장 접합을 검사한다. 통로 중앙만의 광선 통과를 완료 증거로 삼지 않는다.
4. 모든 인접 가장자리와 패널 전체 경로/탑승 공간을 검사한다. 단순 점프로 우회 가능한 간격과 바닥 없는 갇힘 공간을 구분한다. 의미 있는 추락 공간에는 실제 복귀 경로를 둔다.
5. 새 지형의 오류를 정리한 뒤 생성 lint=0·같은 옵션 베이크·정식 HollowContent/ProductionSurfaceDataDefinitions 검사를 수행한다. Support sources/Layers·포털 후보·포털 검사 시간·삼각형 수의 전후 비교를 기록한다. 베이크 해상도를 낮춰 지형 오류를 감추지 않는다.
6. 에디터 외형 확인과 데이터/충돌 검사 후 사용자 PIE 검토를 묶어서 요청한다. 다섯 보고 지점의 통행·접지·자력 복귀·패널 역할을 확인하기 전에는 외피 작업 완료로 기록하지 않는다.

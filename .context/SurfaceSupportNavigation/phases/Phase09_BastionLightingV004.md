# Phase 9 — Bastion 광원 비용 실측·감축 후보 평가 V004

> 상태: 1차 평가 완료, 감축 후보 미채택
> 날짜: 2026-10-12

## 결론과 적용 상태

승인 V003의 광원81개를 유지한다. 외성벽 문4곳의 포인트 광원을 각각3→1개로 합친73개 후보는 직접광 패스 비용을 줄였지만 전체 GPU 시간 개선을 확인하지 못했고 상부 벽 조명도 약해졌다. 코드·LVI·SurfaceData를 변경하지 않았다. 추가 감축은 단위5의 고정 해상도 패키지 GPU 측정에서 필요성이 확인되면 재검토한다. 이번 결과를 광원 최적화 완료나 Phase9 성능 Gate 통과로 해석하지 않는다.

## 방법과 한계

- Unreal MCP로 TestMap03 PIE를 실행했다. 현재 조합은 Bastion3개로 광원243개다. 광원은 그림자 없는 Movable 포인트, 간접광·볼류메트릭 기여도는1이다.
- 적 밀도0, RTX4060 Laptop GPU, D3D12/SM6, WindowsEditor Development, 실제 PIE viewport1039×543이다. 스크린샷만1280×720이다. 패키지·최종 해상도·멀티플레이 비용을 대신하지 않는다.
- 기존 `LNP.Debug.TeleportToReview`의 Cavern·NorthGate·TallBuilding으로 플레이어를 동일 지점에 리스폰했다. 외성벽 문은 같은 Bastion slot4의 local(13700,0,H0)에서 비교했다. 자동 이동 경로나 사용자 자유 탐색 검사는 아니다.
- 조건 전환 후4초 안정화→스크린샷→2초 추가 안정화→CSV6초를 수집했다. 각 CSV의 수치 행에서 앞30/뒤10프레임을 제외하고 GPUTime 중앙값을 비교했다. 프레임 시간은 약60fps로 제한되어 있어 성능 결론에 쓰지 않는다. 한 번의 기존→후보→기존 반복이므로 작은 차이는 확정 이득으로 보지 않는다.
- 처음 임시 ViewTarget으로 만든 시험은 커스텀 플레이어 카메라가 따르지 않아 폐기했다. 최종 기본3시점의 `before/off/before_repeat` 파일은 실제 플레이어 이동 방식으로 다시 수집했다.

## 기존 광원 전체 소등의 영향

단위는 GPUTime 중앙값 ms다. 소등은 Bastion 포인트 광원만 대상으로 하며 플레이어 랜턴·발광 구슬·환경광은 유지했다.

| 시점 | 기존 | Bastion 광원 소등 | 기존 반복 |
|:---|---:|---:|---:|
| 공동 | 6.8324 | 6.2620 | 6.6312 |
| 성채 북문 | 7.5440 | 7.0324 | 7.3968 |
| 고층 건물 | 6.5705 | 6.4543 | 6.5862 |

공동·성채 북문의 차이는 대략0.4~0.6ms, 고층 건물은 약0.12~0.13ms다. LumenSceneUpdate 중앙값은 약0.078~0.081ms로 거의 같다. 전체 소등 결과를 특정 광원8개 제거의 예상 이득으로 환산하지 않는다.

## 감축 후보와 결과

처음 검토한81→65개 후보는 성채·외성벽의 문8곳을 모두3→1개로 합친다. 그림자 없는 기존 감쇠식과 구면 지상 바닥 샘플로 계산했을 때 성채 문은 최대 약38% 어두워져 실제 적용 후보에서 제외했다. 외성벽 문4곳만 합치는81→73개 후보를 PIE에서 비교했다.

외성벽 후보는 기존 각 묶음의 중앙 광원을 유지하고 반경3500→4917.5cm, 실제 unitless 세기를 기존의0.274311647배로 조정했다. 바닥 샘플의 계산상 기존 조도 비율은0.9449~1.0288이다. 이 계산에는 다른 광원·재질·간접광·벽/천장 조도가 포함되지 않으므로 실제 시각 검토를 대체하지 않는다. 제거 후보 광원은 PIE에서 세기0으로 만들어 직접광 기여를 없앴다. Actor 자체 제거·구슬 제거의 CPU 비용은 측정하지 않았다.

| 시점 | 기존 | 73개 후보 | 기존 반복 |
|:---|---:|---:|---:|
| 공동 | 6.8392 | 6.7684 | 6.8256 |
| 성채 북문 | 7.5947 | 7.4102 | 7.3766 |
| 고층 건물 | 6.5307 | 6.5236 | 6.5488 |
| 외성벽 문 | 6.5214 | 6.5300 | 6.3887 |

외성벽 문에서 `GPU/Lights` 중앙값은0.6575/0.6604→0.5694ms, `GPU/RenderDeferredLighting`은0.9108/0.9080→0.8802ms다. 두 패스를 합산해 전체 이득이라고 주장하지 않는다. 직접광 비용은 줄지만 GPUTime은 개선되지 않았고 실제 캡처에서 상부 벽이 어두워졌다. 기존 상태의 반복 편차를 고려해 후보를 채택하지 않았다.

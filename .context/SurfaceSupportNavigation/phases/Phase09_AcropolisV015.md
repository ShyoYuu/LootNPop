# Acropolis_00 V015 — 지면에서 옥탄트 경계로 복귀

2026-10-13. 사용자가 V011의 틈 수정을 확인한 뒤, 내부 지면을 35m 낮춘 상태에서 경계로 걸어 복귀할 수 없다는 문제를 보고했다. 지형 기준본은 **V015**다. 사용자는 설치된 길 모두에서 점프·훅 없이 옥탄트 경계까지 도달하는 것을 확인했다. 이후 신고된 한 구덩이의 탈출 훅 추가는 [V016](Phase09_AcropolisV016.md)에 기록한다.

## 변경

각 좌표 경계 X=0·Y=0·Z=0에 세 곳씩, 총 9개 경사로를 기존 지각에 통합했다. 하단과 상단을 별도 메시로 덧대지 않고 지면의 높이를 연속적으로 바꿔 접합 턱을 피했다. 보행 중심부 폭은 약 30m이며 중앙과 좌우 8m, 총 폭 16m를 검사했다. 각 길은 경계 보존 띠로 이어지며 훅 없이 양방향 보행하는 동선이다.

| 검토점 | 경계 | 배치 각도 | 검사된 최대 경사 |
|:---|:---|---:|---:|
| AcropolisExit_0_01 | X=0 | 20° | 30.79° |
| AcropolisExit_0_02 | X=0 | 43.5° | 29.96° |
| AcropolisExit_0_03 | X=0 | 70° | 29.96° |
| AcropolisExit_1_01 | Y=0 | 20° | 29.96° |
| AcropolisExit_1_02 | Y=0 | 32° | 33.03° |
| AcropolisExit_1_03 | Y=0 | 73° | 28.35° |
| AcropolisExit_2_01 | Z=0 | 20° | 29.96° |
| AcropolisExit_2_02 | Z=0 | 51° | 29.94° |
| AcropolisExit_2_03 | Z=0 | 78° | 40.74° |

각도는 경계 평면의 나머지 두 축 사이 각도이며 옥탄트 접평면 X/Y 각도와 다르다. X 꼭짓점 쪽 두 길은 같은 높이장을 공유하고 길게 돌아가도록 만들어 서로의 경사면이 길을 가르지 않게 했다. 기존 Meadow 원본에 남은 잔굴곡은 복귀로 안에서 완화하되 경계 보존 띠의 원본 좌표는 유지했다.

지각 하나만 재반입했다. 섬·동굴·보스·공중 암석 62개 메시, 훅 28개의 위치/사거리와 훅·Pod 마커 ID 61개를 보존했다. 동굴 절단 경계 주변 원본 정점 3772개가 0.006cm 미만 오차로 보존됐고, 이전 Pocket_05 틈 수정도 재검사했다. 새 복귀로 검토점 9개를 추가하고 기존 Entry 검토점 3개의 높이를 새 지면에 맞췄다.

현재 원본은 `Art/Octants/Acropolis_00/Acropolis_00_V015.blend`다. `BuildAcropolisOctant.py`가 복귀로 높이를 소유하며 `VerifyAcropolisExits.py`가 바닥·경사·동굴 접합 보존과 검토점 좌표를 기록한다. `ReviseAcropolisOctant.py`는 기존 Geometry Actor와 게임플레이 마커를 재발급하지 않고 지각 및 검토점만 갱신한다.

## 검증과 다음 플레이

- 원본에서는 9개 길의 바닥·경사 검사와 기존 24개 섬 연결, Pod 바닥, 동굴, 이전 틈 검사가 통과했다.
- 엔진의 `VerifyAcropolisReady.py`는 경사로의 중앙·양 가장자리 바닥 광선을 저장 원본 좌표와 비교한다. 이 검사는 캡슐 sweep이나 실제 Mover 왕복 성공을 대신하지 않는다.
- 최종 엔진 광선 2286개가 통과했고 원본 바닥과의 최대 오차는 0.0054cm 미만이다. 기존 틈 검사 201개, 마커 ID 61개 보존과 새 검토점 9개 위치 검사도 통과했다. 나머지 Authored 62개 에셋은 파일 SHA256이 수정 전과 동일하다.
- 경계·스폰·저장 베이크 현재성의 기존 네이티브 자동 검사 3개는 오류 0·경고 0으로 통과했다. 현재 SurfaceData는 Nav 136706 cells, Traversal 43147 bytes, Spawn 482656 bytes다. Support 표본 2344601개와 이음매 규격을 보존했다.
- native 경계 정점 13989개 복원과 seam 표본 2208개 일치 규약을 유지한다.
- 재베이크는 기존 SurfaceData 경로에 수행했다. 실제 OctantPoolData와 전역 설정 파일은 수정하지 않는다.
- 기술 검증 보고서와 세부 로그는 `Saved/SliceOctant/Acropolis_00/V015/`에 보존한다. 이전 V012~V014 후보는 합류부와 원본 잔굴곡 때문에 제외했고 에디터에 채택하지 않았다.
- 최종 저장 후 `TestMap03`과 Acropolis DA를 선택한 상태로 인계하며, 이번 변경의 실제 보행 PIE는 사용자에게 요청한다.

`TestMap03`에서 PIE를 시작한 뒤 아래 검토점으로 이동한다. 경사로 하단에서 경계까지 **걷기 → 이웃 옥탄트로 넘어가기 → 같은 길로 내려오기**를 확인한다. 점프·훅 없이 통과해야 한다. 먼저 세 경계의 대표 길을 확인하고, 이후 모서리의 긴 복귀로 `AcropolisExit_1_03`·`AcropolisExit_2_03`을 본다.

```text
LNP.Debug.TeleportToReview AcropolisExit_0_02
LNP.Debug.TeleportToReview AcropolisExit_1_02
LNP.Debug.TeleportToReview AcropolisExit_2_02
```

문제가 있으면 `LNP.Debug.WhereAmI`와 이동 방향을 기록한다. 사용자가 V015의 모든 경계 상승을 확인했다. 위 절차의 이웃 옥탄트 왕복 전체와 NPC 교전까지 확인한 것으로 확대하지 않는다.

# Hollow_00 전체 단순화 재제작 인계

2026-10-10 사용자 지시. 기존 국소 접합 보정 위주의 [외피 재제작안](Phase09_HollowExteriorRebuild.md)보다 이 문서를 우선한다. 전체 재제작은 아래 V017~V020 결과로 완료됐다. 후속 세션은 이 문서와 [Current](../Current.md), [설계 가이드](../../Guide_OctantLevelDesign.md), [제작 가이드](../../Guide_OctantLevelInstance.md)를 완료 기준과 재사용 절차로 참고한다.

**실행 갱신:** [V017 외피](Phase09_HollowLowPolyV017.md)는 베이크·장치 포함 정식2개 검사와 사용자 전체 PIE 탐색을 거쳐 확정됐다. 틈/한쪽 면/깨진 형상 보고0, 전체165086 tris로 기준 대비63.61% 감소다. [V018](Phase09_HollowDevicesV018.md)의 패널 면적9배, [V019](Phase09_HollowDevicesV019.md)의 정돈된 훅 역할·시드 혼입 차단·Shuttle 서쪽 절벽 연결·중력 수평 회전은 채택됐다. 특히 V019 패널은 호스트·게스트 PIE에서 모두 성공했다. **잔도 관성 착지/정상 도착/외곽 복귀의 최신 [V020](Phase09_HollowDevicesV020.md)은 WestMid 첫 Chaos5방향 실패를 수정했다. 임시 후보 적용 제거·Live Coding patch_5·재생성 lint0·베이크 완료 후 저장 조립 정식2검사 모두 성공(3.393초/오류0/경고0). 25접근/22착지/643관성낙하/1044패널 sweep을 통과했고 승인 외피8개 SHA256와 패널 BP 일치다. 2026-10-11 사용자도 마지막 변경 구간 PIE를 “검토 완료, 문제 없음”으로 확인해 전체 단순화 재제작과 장치·훅 조정을 완료했다.** 큰 구성/복구는 [V010](Phase09_HollowLowPolyV010.md), 외피/분할 수정은 [V016](Phase09_HollowLowPolyV016.md)에 있다. 아래 직전 상태는 작업 시작 시점의 비교 기준이다.

## 새 목표와 허용 범위

- 후보 구역만이 아니라 **Hollow_00 전체**를 간결한 폴리곤 조립으로 재제작한다. 프로토타입에서 디테일한 쉐입을 다듬는 작업은 중단하고 정식 아트 적용 단계로 미룬다.
- 기존 쉐입을 크게 바꾸거나 세부 동선을 조정해도 된다. 과거의 정확한 폭·굽이·형상 보존 지시는 이번 전체 단순화에 대한 제약으로 사용하지 않는다. 주 이동·전투·탐색의 역할을 새 배치에서 다시 연결한다.
- 닫힌 직육면체 판·쐐기·누운 삼각기둥·단순 암반을 우선한다. 절벽 잔도의 ㅗ 단면이나 장식 밑동은 필수가 아니다. 얇은 판도 측면과 밑면을 가진 닫힌 몸체로 만든다.
- 메시 구멍, 외부에서 일방 통과되는 면, 탈출 불가능한 함정 지형을 우선 제거한다. 작은 보정 메시를 계속 덮기보다 큰 덩어리의 위치·폭·간격과 동선을 함께 바꾼다.
- 함정 해소에 과도한 형상 수정이 필요하면 **탈출 훅 앵커**를 허용한다. 앵커까지의 시야·도달 경로·출구 착지와 발견 가능성을 확인한다.
- 월드 반지름300m·옥탄트 이음매 계약은 유지한다. Hollow의 협곡·높이차·하층·보스 랜드마크라는 큰 경험을 단순한 형상으로 표현한다. Pod8개와 편성은 기준으로 유지하되 새 형상에 맞춰 위치와 검토 좌표를 옮길 수 있다.
- NPC LoS/런타임 이동은 별도 세션 범위다. 지형 오류를 Mover 변경이나 양면 렌더링/양면 충돌로 감추지 않는다.

## 검증 순서

1. 현재 코드·에셋을 복구 가능하게 보존하고 전체 형상/삼각형 수를 분류한다. 지각, 협곡·절벽, 공동·입구, 잔도, 왕복 경사, 외곽 진입, 부유섬, 아레나별로 소유 원본과 교체 대상을 정한다. 현재 0.5cm급 보정·높은 세분화를 모든 면에 유지하는 것을 목표로 삼지 않는다.
2. 평면·단면·연결표를 단순한 덩어리 기준으로 정리하고 **전체 재제작 후보를 한 묶음으로 완성**한다. 단순하고 규칙적인 덩어리는 코드, 이어진 외피·굴은 Blender를 사용하되 제작 도구가 형상 복잡도를 늘리는 이유가 되지 않게 한다. 재제작 때 같은 자리에 있던 구형 Generated/Authored와 국소 보정 형상을 함께 제외한다.
3. 제작 중 토폴로지·면 방향·중복·의도하지 않은 열린 경계와 접합을 검사한다. 구면 분할은 실제 보행/충돌에 필요한 만큼만 추가한다. 모서리를 맞추기 어려운 접합은 작은 보정 대신 큰 형상이나 배치를 바꾼다. 옥탄트 경계의 공유 단면은 별도 계약이다.
4. 전체 반입·생성 후 베이크와 자동 검증을 반복해 기술 오류를 먼저 정리한다. 실제 적용된 메시와 Support 참조, 씬의 중복, 이음매, 주요 경로/Pod·편성·장치 역할을 검사한다. 새 배치에 맞춰 검사 좌표는 갱신하되 실패를 숨기기 위해 연결/충돌 기준을 낮추지 않는다. 각 국소 수정마다 사용자 PIE를 요청하지 않는다.
5. 자동 검증을 마친 전체 후보를 사용자 PIE로 한 번에 검토한다. 주요 왕복 동선, 측면/하부 접근, 추락 후 복귀, 훅 탈출과 패널 기능을 묶는다. PIE에서 드러난 문제는 큰 형상·배치 조정을 우선해 수정하고 영향을 받은 자동 검증을 다시 통과시킨 후 재검토한다.

생성·베이크 콘솔 API는 현재 없다. 제작 가이드 §6에 따라 필요한 수동 Build/Bake만 묶어 요청한다. 자동 검증 먼저라는 지시가 제작 중 정적 메시 검사까지 마지막으로 미루라는 뜻은 아니다.

## 완료 기준과 비용 비교

- 의도하지 않은 외피 구멍/방향 불일치/중복 면은0이며 실제 조립과 충돌에서도 확인한다. 서로 묻힌 닫힌 몸체를 사용할 때는 접근 가능한 빈 틈과 불필요한 내부 Support가 남는지 함께 본다. Boolean Union을 모든 덩어리에 강제하지 않는다.
- 주요 이동·전투·장치 연결은 새 설계와 정식 검사에서 성립한다. 도달 가능한 추락 공간에는 걷기·점프·훅 중 실제 사용할 수 있는 탈출 방법이 있다.
- 삼각형 총량과 큰 기여 구역의 감소를 수치로 제시한다. 단순히 면 수를 줄였다는 이유로 성능 향상을 확정하지 않는다. Support sources/Layers, 포털 후보와 검사 시간, payload도 같은 옵션으로 비교한다.
- 최종 완료는 사용자 PIE 검토 후다. Blender 반입 성공·manifold0·Nav 검사 통과 각각의 범위를 구분한다.

## 직전 상태와 중간 후보 주의

현재 저장된 production 조립/SurfaceData는 **BackPocketV015 + EastRimV006**이다. 서쪽은 보고 지점 통행과 세로 틈 해소를 사용자가 확인했다. 동쪽은 생성·베이크·정식2개 검사는 통과했지만 **사용자 PIE는 실패**했다.

동쪽 보고는slot2/local(−10444,9248,H−428), 작은 바닥 구멍과 이어진 벽 통과 후 Falling 지속/탈출 불가다. WhereAmI 좌표는Pawn 중심이며 발밑5m 광선은none이었다. 형상·캡슐 진단의 범위를 실제 조립 폐쇄로 확대하지 않는다.

Blender V006 에셋은 그대로다. 최종 외피와2,712곳 비교는 바깥0/최소 매입3.626cm였으나 **수정 후 생성·베이크·PIE는 확인되지 않았다.** 수동 Build 요청은 이번 전체 단순화 지시로 보류했다. 이 후보를 이미 production 검증된 수정으로 취급하거나 새 세션에서 국소 보정부터 재개하지 않는다. 전체 재제작에서 기존 ReplaceBackPocketRegion/ReplaceEastRimRegion과 버전 preflight를 새 소유 구조에 맞춰 함께 정리한다.

현재 에디터는TestMap03, PIE는 종료했다. 현재 슬롯 번호를 다음 PIE에서 재사용하지 않는다. 사용자 지시 이후 추가 생성/베이크는 실행하지 않았다.

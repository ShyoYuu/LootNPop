# 인게임 메뉴 기획서

## 1. 목표와 원칙

- CommonUI 모듈로 **게임패드 우선** 조작이 성립하는 인게임 메뉴를 만든다. 마우스는 보조 수단으로 병행 지원한다.
- 모든 조작 설명은 **PlayStation 게임패드**(듀얼쇼크/듀얼센스) 기준으로 기술한다.
- MVVM 활용이 가능한 곳은 MVVM 모듈 기능을 우선 사용한다. (단, 리스트/타일 데이터는 MVVM 바인딩 불가 — [TechDesign_HUD.md](TechDesign_HUD.md) §8에 기록된 제약)
- 화면 중앙 **팝업** 형태로 크게 띄우되 전체 화면을 완전히 가리지 않는다.
- 모든 UI 요소는 **반투명**으로 만들어, 메뉴를 보는 중에도 긴급 상황(피격·적 접근)을 눈치챌 수 있게 한다.

---

## 2. 열기 / 닫기 / 일시정지

| 입력 | 동작 |
|:---|:---|
| 터치패드 버튼 (→ `Gamepad_Special_Left`) / 키보드 `I` | 마지막으로 보던 탭으로 진입. **다시 누르면 닫힘** |
| 옵션 버튼 (`Gamepad_Special_Right`) / 키보드 `O` | **항상 환경설정 탭**으로 진입. **다시 누르면 닫힘** |
| ○ 버튼 (`Gamepad_FaceButton_Right`) / 키보드 `Esc`·`↑` | 메뉴 닫기 (포커스가 하위 패널에 있으면 먼저 상위로 복귀) |

**키보드 개발 편의 매핑** — 게임패드 없이도 전부 조작할 수 있게 보조 키를 둔다.

| 게임패드 | 키보드 |
|:---|:---|
| L1 / R1 (탭 이동) | `Q` / `E` |
| ✕ (선택·디테일 진입) | `Enter` / `Space` |
| ○ (뒤로·닫기) | `Esc` |
| D-Pad·좌스틱 (Grid 셀 이동) | `←↑→↓` / `WASD` |

> ⚠️ **화살표는 방향 이동 전용으로 비워 둔다.** UI 액션(탭 이동·선택·뒤로)에 배정하면
> 액션이 방향키를 먼저 소비해 인벤토리 Grid의 셀 이동이 불가능해진다.
> 왼손이 WASD에 놓인 상태에서 `Q`/`E`(탭)·`Space`(선택)·`Esc`(뒤로)로 전부 닿는 배치다.

> ⚠️ 기획 원안의 "터치패드 버튼"은 Windows의 XInput/Raw Input 경로에서 UE에 키 이벤트가 전달되지 않는다.
> 물리 버튼 위치가 가장 가까운 `Gamepad_Special_Left`(Share/Create 버튼)로 대체한다.
> DualSense 전용 입력 플러그인을 도입하면 실제 터치패드 버튼으로 교체할 수 있다.

### 마지막 탭 기억 규칙

- 캐릭터 스탯 탭과 인벤토리 탭 중 **닫기 직전에 보던 탭**으로 진입한다.
- 게임 실행 후 첫 진입이거나, 마지막으로 보던 탭이 환경설정 탭이었다면 → **캐릭터 스탯 탭**으로 진입한다.
- 즉 환경설정 탭은 "기억 대상"이 아니다. 옵션 버튼으로만 직행한다.

### 일시정지

- 스탠드얼론일 때만 메뉴를 열면 게임을 일시정지한다. **멀티플레이에서는 일시정지하지 않는다.**
- 멀티에서는 메뉴를 보는 동안에도 캐릭터가 피격될 수 있다 — 반투명 설계가 이를 보완한다.

### 게임플레이 입력 차단

- 메뉴가 열려 있는 동안 폰의 입력 매핑 컨텍스트를 제거해 이동·시점·공격·상호작용을 **전면 차단**한다.
- 이유: 게임패드 좌스틱이 Grid 커서 이동과 캐릭터 이동을 동시에 일으키는 충돌을 원천 차단한다.
- 닫을 때 원래 컨텍스트를 복원한다.

## 3. 레이아웃

```
┌─────────────────────────────────────────────────────┐
│  ┌──────────┬──────────┬──────────┐                 │  ← 상단 탭 팝업
│  │ 캐릭터   │ 인벤토리 │ 환경설정 │   L1 ◄  ► R1    │    (현재 탭은 스케일 확대)
│  └──────────┴──────────┴──────────┘                 │
│                                                     │  ← 빈 공간 (두 팝업이 분리되어 보이게)
│  ┌───────────────────────────────────────────────┐  │
│  │                                               │  │  ← 하단 메인 팝업
│  │              (탭 컨텐츠 영역)                 │  │
│  │                                               │  │
│  └───────────────────────────────────────────────┘  │
│                                                     │
│              [○ 닫기] [✕ 선택] [L1/R1 탭]           │  ← 하단 액션 바
└─────────────────────────────────────────────────────┘
```

- 상단 탭 바와 하단 메인 패널 사이에 **의도적인 빈 공간**을 둔다. 하나의 창이 아니라 **두 개의 팝업**이 동시에 떠 있는 느낌을 준다.
- 상단 탭에서 **현재 출력 중인 카테고리는 스케일을 살짝 확대**해 강조한다.
- 배경은 `BackgroundBlur` + 반투명 어두운 오버레이. 게임 화면이 흐릿하게 비쳐 보인다.
- 하단 액션 바는 현재 포커스에서 가능한 조작을 아이콘 + 라벨로 표시하며, **키보드/게임패드 전환 시 아이콘이 자동으로 바뀐다**.

---

## 4. 탭 이동

- `L1` / `R1`으로 좌우 카테고리 이동. 양 끝에서의 순환 여부는 CommonUI 기본 동작(순환)을 따른다.
- 카테고리는 **캐릭터 스탯 / 인벤토리 / 환경설정** 3종. 추후 카테고리 추가가 가능한 구조로 만든다.

## 5. 캐릭터 스탯 탭

세 영역이 위에서 아래로 배치된다.

### 5-1. 스탯 리드아웃

캐릭터 AttributeSet의 스탯을 다음 포맷으로 출력한다.

```
최종값(합연산결과 + 곱연산증가량)
 흰색    회색        초록
```

예시:

```
HP             150 / 150
공격력         36.0 (30.0 + 6.0)
공격속도       1.30 (1.00 + 0.30)
방어력         50.0 (50.0 + 0.0)
이동속도       1.30 (1.30 + 0.0)
루팅속도       2.00 (1.00 + 1.00)
```

**표시 스탯은 6행이다.** `AttackPower`와 `AttackMultiplier`는 **별도 행으로 나누지 않는다** —
둘 다 "공격력"이라는 하나의 스탯을 계산하기 위한 재료 값이므로 **`공격력` 한 행으로 합쳐서** 보여준다.
(실제 데미지 공식도 `(AttackPower + 무기보너스) × AttackMultiplier`로 동일한 관계다.)

#### 색상 의미 (버프 시스템 개선 전제)

- **합연산 버프**는 장비 아이템이나 영구 적용으로만 들어온다. 따라서 UI에서 버프량으로 따로 보이지 않고
  **기본 스탯에 합산된 것처럼** 회색으로 표기한다.
- **곱연산 버프**만 초록색 증가량으로 보인다. 곱연산은 합연산이 모두 적용된 뒤에 곱해진다.
- 기획 원안의 "검은색"은 어두운 반투명 배경에서 보이지 않으므로 **흰색**(기본 텍스트 색)으로 대체한다.
- 곱연산 증가량이 0이어도 괄호 표기를 유지한다 (`(30.0 + 0.0)`).

> ⚠️ 이 표기는 향후 버프 시스템 개선(모든 스탯에 합/곱 버프 도입)을 전제로 미리 깔아두는 기반이다.
> 현재 콘텐츠에는 합연산 버프만 존재하므로 초록색 부분은 대부분 0으로 표시된다.

### 5-2. 장착 장비

- 현재 장착 중인 **무기 슬롯 1칸**의 아이콘만 간단히 표시한다.
- 슬롯이 비어 있으면 플레이스홀더를 표시한다.
- 스킬 슬롯은 이번 범위에서 제외한다 (스킬 장착 UI가 아직 없음).

### 5-3. 적용 중인 버프

- 현재 적용 중인 버프들의 **아이콘 + 남은 시간**만 간단히 가로로 나열한다.
- 남은 시간은 1초 주기로 갱신된다.
- 지속시간이 무한인 버프는 시간 표기를 생략한다.

## 6. 인벤토리 탭

좌우 2분할. 좌측 Grid, 우측 디테일.

```
┌──────────────────────────┬─────────────────────┐
│ ┌──┐┌──┐┌──┐┌──┐┌──┐     │  ┌────┐             │
│ │  ││  ││  ││  ││  │     │  │아이│  아이템 이름 │
│ └──┘└E─┘└──┘└──┘└──┘     │  │ 콘 │             │
│ ┌──┐┌──┐┌──┐             │  └────┘             │
│ │  ││  ││  │             │  설명 / 스탯        │
│ └──┘└12┘└──┘             │                     │
│                          │  [ Equip ] [ Drop ] │
└──────────────────────────┴─────────────────────┘
    ✕ → 디테일로              ○ → Grid로
```

### 6-1. 좌측 Grid 패널

- 보유 중인 **무기·버프·기타 아이템을 모두** 직사각형 아이콘 셀로 표현한다.
- 열 수는 고정, 아이템 개수만큼 셀이 동적으로 생성되고 세로 스크롤된다.
- **방향키 / L3 스틱**으로 Grid 상에서 셀 간 이동. 선택된 셀은 하이라이트된다.
- 셀 하단에 작은 배지를 표시한다:
  - **무기 아이템** → 장착 여부
  - **버프 아이템** → 남은 시간 (초, 1초 주기 갱신)
- **장착 중인 무기도 Grid에 표시된다.** 기존 인벤토리 패널은 장착본을 숨겼으나,
  본 기획이 "장착 여부 표시"를 요구하므로 노출로 변경한다.
- `✕` 버튼으로 포커스를 **Grid → 디테일 패널**로 이동한다.

### 6-2. 우측 디테일 패널

- 현재 Grid에서 선택된 아이템의 상세 정보를 표시한다: 큰 아이콘, 이름, 종류, 설명/스탯.
- **Equip 버튼**과 **Drop 버튼**이 이곳에 위치한다.
  - **Equip**: 무기 아이템에만 표시. 이미 장착 중이면 비활성 + "장착 중" 표기.
    무기 슬롯이 1개이므로 다른 무기를 장착하면 자동 교체된다 — 별도 Unequip 버튼은 두지 않는다.
  - **Drop**: 장착 중이 아닌 아이템에만 활성. 버프 아이템도 드랍 가능하며 잔여 시간을 유지한 채 LootDice로 스폰된다.
- 포커스가 디테일 패널에 있을 때 `○` 버튼으로 **디테일 → Grid**로 포커스를 되돌린다.
  이때 `○`는 메뉴 닫기로 이어지지 않는다.
- Grid가 비어 있으면 디테일 패널은 "아이템 없음" 안내를 표시한다.

## 7. 환경설정 탭

- 현 범위에서는 **빈 패널 + "준비 중" 안내 문구**만 배치한다.
- 탭 자체는 정상 동작하며(진입/이탈/액션 바), 내용만 추후 채운다.

# LootPod System - 게임 기획서

## 1. 개요

**LootPod**은 LootNPop 월드 전역에 배치되는 핵심 상호작용 오브젝트. 플레이어는 적들의 방해를 뚫고 Pod를 루팅하여 강력한 무기·버프·스킬을 획득하고, 이를 써서 적들을 날려버리는 것이 게임의 핵심 루프.

---

## 2. 핵심 루프: "Find → Loot → Pop!"

### 2.1 발견 (Find)

- 월드 곳곳에 무작위로 스폰되며, **빛기둥(Light Pillar)** 이펙트로 원거리에서도 식별 가능.
- **빛기둥은 순수 엔티티 상태(Low LOD)에서도 보여야 한다** — "멀리서도 보인다"가 스펙이므로 근접 Actor(High LOD) 유무와 무관하게 상시 표시. ✅ 구현 완료 (Low LOD ISM 에미시브 빔 — 2026-07-12, → [TechDesign_LootPod.md](TechDesign_LootPod.md) §5.4)
- 메인 내벽과 부유 행성 외부 표면 모두에 배치.

### 2.2 루팅 (Loot)

1. LootPod의 **단말기 조작 거리(초근접, 기본 1.5m)·정면 각도** 이내로 접근하면 상호작용 입력(Interaction Input)이 활성화된다 — Pod에 달린 단말기를 플레이어가 직접 조작하는 컨셉. (조작 정렬용 모션 워핑 아이디어 → [Idea_Backlog.md](Idea_Backlog.md))
2. 입력을 누르면 루팅 시작 — 바닥에 **루팅 존(Looting Zone, 반경 5m)** 홀로그램 링이 표시되고 게이지가 차오른다.
3. **홀로그램 링(게이지)이 다 채워질 때까지 루팅 존 안에서 버텨야 한다.** 존 안의 인원은 게이지 회복에 기여하는 동시에 존을 사수해야 한다.

> **반경 2종 분리:** 상호작용(루팅 State 진입)은 초근접 — 루팅 존(기여·사수 판정)은 5m. 두 값 모두 Pod 종류별 config로 조정 가능 (여러 종류의 LootPod 대비).

**버티기 게임플레이 — 게임의 핵심 재미와 직결:**

과장되고 웃긴 넉백이 이 게임의 특징. 루팅 중 적의 공격에 맞으면 존 밖으로 날아가 버린다. 넉백으로 날아가지 않고 루팅 존 안에서 버티려면 동료들과 함께 Enemy NPC들을 효과적으로 제압해야 한다.

**취소 조건 (2026-07-09 개정):**

| 조건 | 결과 |
|:---|:---|
| 루팅 존에 루터가 한 명도 없음 (자발적 이탈·넉백 피탈 모두 포함) | 루팅 일시 중단 — 존은 활성 유지, 게이지가 **서서히 감소(Decay)** |
| 감소 끝에 **게이지 0 도달** | **루팅 프로세스 완전 취소** — 루팅 존 비활성화, 취소 연출 |

**재개 규칙:**

- **게이지가 0이 되기 전에 복귀:** 누구든 루팅 존에 다시 들어가기만 하면 잔여 게이지부터 재개된다 (Interaction Input 불필요).
- **완전 취소 후:** 존 재진입만으로는 재개되지 않는다 — 아무나 LootPod까지 접근해 **Interaction Input으로 루팅 존을 활성화하는 프로세스부터 다시** 해야 한다.

> **"피격 시 즉시 취소" 조건 폐기:** 피격 자체는 루팅을 끊지 않는다. 넉백으로 존 밖까지 밀려나는 것이 곧 중단이며, "존 사수"가 핵심 재미이므로 피격-취소를 별도로 두면 넉백 게임플레이가 무의미해진다. (기존 HitDetection 연동 취소 계획은 불필요해짐 — 넉백 이동에 의한 존 이탈은 기존 범위 체크가 자동으로 감지)
>
> **게이지 감소(Decay) 방식 확정:** 전원 이탈 시 게이지는 즉시 초기화되지 않고 서서히 감소한다 — 넉백으로 튕겨나가도 게이지가 0이 되기 전에 복귀하면 진행분을 지킬 수 있어 존 사수 게임플레이와 맞물린다. 감소 속도는 **const 값 1개**로 제어하며, 값을 크게 올리면 즉시 초기화 룰도 바로 테스트 가능.

**루팅 속도:**

- 플레이어에게 **루팅 속도 스탯**이 있으며, 이에 상응하는 버프 아이템/효과가 존재한다.
- **멀티플레이 협동:** 루팅 존 안에 있는 파티원이 많을수록 속도가 합산되어 더 빠르게 루팅된다.

**방해 요소:** 주변의 적 NPC는 루팅 중인 플레이어를 최우선 타겟으로 지정.

### 2.3 획득 (Pop!)

- 게이지가 완료되면 LootPod이 파열(`Popped`)되며 **축하 이펙트(나이아가라, Confetti)** 와 함께 보상이 튀어나온다.
- 모든 보상은 **[LootDice](GameDesign_LootDice.md)** — 아이콘이 그려진 주사위(큐브) 형태의 픽업 아이템으로 월드에 드랍된다. 강한 회전과 함께 튀어나와 바닥에서 구르다 멈춰야 아이콘이 보이는 "주사위 굴림" 연출 (→ [GameDesign_LootDice.md](GameDesign_LootDice.md) §3). 즉시 적용이 아니라, 파티원들이 아이콘을 보고 논의해 **필요한 플레이어가 선택적으로 획득**하는 전략적 분배가 의도.

## 3. 보상 유형

| 유형 | 예시 | 비고 |
|:---|:---|:---|
| **Weapons** | 거대 해머, 고무공 발사기, 중력 건 | 교체 가능한 장비 |
| **Buffs** | 이동 속도 증가, 캐릭터 거대화, 점프력 강화 | 지속 시간 존재 |
| **Skills** | 순간이동, 광역 넉백, 보호막 | 쿨타임 기반 액티브 스킬 |
| **Items** | 회복 키트, 함정 설치기, 일회용 투척물 | 소모성 아이템 |
| **Gimmicks** | 고정형 터렛 탑승권, 점프 패드 활성화 | 환경 상호작용 |

- 보상 종류는 `PodID`를 통해 외부 데이터 에셋으로 관리. 코드 수정 없이 보상 유형을 추가·변경 가능.
- 유형 식별은 LootDice의 아이콘·카테고리 색상이 담당 (→ [GameDesign_LootDice.md](GameDesign_LootDice.md) §2).

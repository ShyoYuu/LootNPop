# LootPod System - 게임 기획서

## 1. 개요

**LootPod**은 월드 전역에 배치되는 핵심 상호작용 오브젝트. 적의 방해를 뚫고 Pod를 루팅해 강력한 무기·버프·스킬을 얻고, 그것으로 적을 날려버리는 것이 게임의 핵심 루프다.

---

## 2. 핵심 루프: "Find → Loot → Pop!"

### 2.1 발견 (Find)

- 월드 곳곳에 무작위로 스폰되며, **빛기둥(Light Pillar)** 으로 원거리에서도 식별된다.
- **빛기둥은 순수 엔티티 상태(Low LOD)에서도 보여야 한다** — "멀리서도 보인다"가 스펙이므로 근접 Actor(High LOD) 유무와 무관하게 상시 표시. ✅ 구현 완료 (→ [TechDesign_LootPod.md](TechDesign_LootPod.md) §5.4)
- 메인 내벽과 부유 행성 외부 표면 모두에 배치.

### 2.2 루팅 (Loot)

1. Pod에 달린 단말기를 직접 조작하는 컨셉 — **초근접 거리(코드 기본 250cm)·정면 60°** 안에서만 상호작용 입력이 활성화된다. (조작 정렬용 모션 워핑 아이디어 → [Idea_Backlog.md](Idea_Backlog.md))
2. 입력을 누르면 루팅 시작 — 바닥에 **루팅 존(Looting Zone, 반경 5m)** 홀로그램 링이 뜨고 게이지가 차오른다.
3. **링(게이지)이 다 찰 때까지 존 안에서 버텨야 한다.** 존 안의 인원은 게이지에 기여하는 동시에 존을 사수한다.

> **반경 2종 분리:** 루팅 State 진입은 초근접(단말기 조작) — 게이지 기여·사수 판정은 존 반경 5m. 두 값 모두 Pod 종류별 config로 조정한다.

**버티기 게임플레이 — 게임의 핵심 재미:**

과장되고 웃긴 넉백이 이 게임의 특징이다. 루팅 중 적의 공격에 맞으면 존 밖으로 날아간다. 존 안에서 버티려면 동료와 함께 적을 제압해야 한다.

**취소 조건 (2026-07-09 개정):**

| 조건 | 결과 |
|:---|:---|
| 존에 루터가 한 명도 없음 (자발적 이탈·넉백 피탈 모두) | 루팅 일시 중단 — 존은 활성 유지, 게이지가 **서서히 감소(Decay)** |
| 감소 끝에 **게이지 0 도달** | **루팅 프로세스 완전 취소** — 존 비활성화 |

**재개 규칙:**

- **게이지 0 이전 복귀:** 누구든 존에 다시 들어가기만 하면 잔여 게이지부터 재개 (Interaction Input 불필요).
- **완전 취소 후:** 존 재진입만으로는 안 된다 — 다시 Pod까지 접근해 **Interaction Input부터** 밟아야 한다.

> **"피격 시 즉시 취소" 폐기:** 피격 자체는 루팅을 끊지 않는다. 넉백으로 존 밖까지 밀려나는 것이 곧 중단이며, 피격-취소를 따로 두면 "존 사수"라는 넉백 게임플레이가 무의미해진다.
>
> **감쇠(Decay) 방식 확정:** 전원 이탈 시 게이지는 즉시 초기화되지 않고 서서히 줄어든다 — 넉백으로 튕겨나가도 0이 되기 전에 복귀하면 진행분을 지킨다. 감쇠 속도는 **const 값 1개**라 크게 올리면 즉시 초기화 룰도 바로 테스트된다.

**루팅 속도:**

- 플레이어에게 **루팅 속도 스탯**(`LootSpeed`)이 있고, 이를 올리는 버프 아이템이 존재한다.
- **멀티플레이 협동:** 존 안의 파티원이 많을수록 속도가 합산되어 빨라진다.

**방해 요소:** 주변 적 NPC가 루팅 중인 플레이어를 최우선 타겟으로 노린다 — ⏸ **미구현**(현재 타겟 점수는 거리 하나뿐). 설계 의도와 튜닝 함정은 [GameDesign_EnemyNPC.md](GameDesign_EnemyNPC.md) §4.2.

### 2.3 획득 (Pop!)

- 게이지가 차면 Pod이 파열(`Popped`)되며 **축하 이펙트(Confetti)** 와 함께 보상이 튀어나온다.
- 모든 보상은 **[LootDice](GameDesign_LootDice.md)** — 아이콘이 그려진 주사위 픽업으로 월드에 드랍된다. 강한 회전과 함께 튀어나와 바닥에서 구르다 멈춰야 아이콘이 보이는 "주사위 굴림" 연출 (→ [GameDesign_LootDice.md](GameDesign_LootDice.md) §3). 즉시 적용이 아니라 파티원이 아이콘을 보고 논의해 **필요한 사람이 선택적으로 획득**하는 분배가 의도다.

## 3. 보상 유형

| 유형 | 예시 | 비고 |
|:---|:---|:---|
| **Weapons** | 거대 해머, 고무공 발사기, 중력 건 | 교체 가능한 장비 |
| **Buffs** | 이동 속도 증가, 캐릭터 거대화, 점프력 강화 | 지속 시간 존재 |
| **Skills** | 순간이동, 광역 넉백, 보호막 | 쿨타임 기반 액티브 스킬 |
| **Items** | 회복 키트, 함정 설치기, 일회용 투척물 | 소모성 아이템 |
| **Gimmicks** | 고정형 터렛 탑승권, 점프 패드 활성화 | 환경 상호작용 |

- 보상 후보는 `PodID`별로 데이터 에셋(`DA_LootDiceRewardTable`)이 관리한다 — 코드 수정 없이 추가·변경 가능. 현재 등록된 것은 무기 3종·버프 6종이며 Pop당 3~4개가 가중 추첨된다.
- 유형 식별은 LootDice의 아이콘·카테고리 색상이 담당 (→ [GameDesign_LootDice.md](GameDesign_LootDice.md) §2).

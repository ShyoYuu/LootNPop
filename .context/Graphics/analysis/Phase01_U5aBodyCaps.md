## 2. 캡과 경계 보정

35430/116462의 닫힌 캡은 각각 약289.19㎡였다. 기존 V007 이진 몸체와 원래 fallback 외피만 읽었다. 기존 생성기·Cull·원래 배치·베이크는 재실행하지 않았다.

하부 공동 몸체는 R03/R04를 잇는 반경2.25m 중심과 바닥을 유지했다. 바깥 상면816정점만 최대44.09cm 낮춰 직선 경계의 높이에 변화를 줬다. R03/R04 기록점은 계속 같은 하부 몸체 부피 안이다. R01은 기존 경계에서 약2cm인 점이라 홀짝 판정이 입력 반올림에 민감했고 새 후보에서는 바깥으로 기록됐다. 이를 R01 전체 폐쇄 완료로 표시하지 않는다. 원래 R01~R06 제보를 재수집하거나 개별 원본 삭제로 처리하지 않았다.

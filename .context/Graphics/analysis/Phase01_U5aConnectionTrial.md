# Phase 1-BR U5a-3 StairRamp3 별도 연결 초안

현재 최신 기준은 사용자 유지 **U5aBody_V006**이며 다음 U5a-6은 새 세션으로 넘겼다. [현재 인수인계](Phase01_U5aBodyHandoff.md)를 우선하고 아래 수치/대기 상태는 당시 시험 이력으로 읽는다.

> 확인: 2026-11-25
> 기준: GX-034~036 · [이전 몸체 보정](Phase01_U5aBodyRefinement.md)

후속: 사용자가 “유지하고 계속 진행하자”로 이 동선 유지를 승인했다. V004 맵/연결V011/저작본은 보존하고 새 V005의 [U5a-4 석재 외형](Phase01_U5aStoneRefinement.md)으로 이어갔다. 아래 채택 대기 표현은 U5a-3 완료 당시 기록이며 전체 몸체·충돌 채택으로 확대하지 않는다.

## 1. 결과와 소유권

사용자가 북쪽 합류 지점을 포함한 구상을 실제로 배치해 결과물로 확인하도록 승인했다. 기존 U5aBody_V003을 새 **U5aBody_V004**에 복제하고 연결 StaticMeshActor1개만 더했다. 기존4몸체·채택21소유자·기존 Z1과 원본/공유 에셋은 고정했다. 현재 몸체/연결 모두 미채택 시각 초안이다.

- 현재 맵: `/Game/Maps/_WorkInProgress/Ridge_00/Graphics/EDTerrain_V001/U5aBody_V004/LVI_Ridge_EDTerrain_U5aBody_V004`.
- 새 액터: `CONN_StairRamp3_V011`, 메시 `U5aBody_V004/ConnectionMeshes_V011/SM_Ridge_StairRamp3_Connection_V011`.
- 맵 판V004와 새 연결 형상 판V011을 구별한다. 이 연결V011은 채택 **U4Layout_V011** 및 원래 **Z1Bake_V010**과 별개다.
- 새1개4,000삼각형·Static·Decoration/LNPDecoration·NoCollision·월드 identity다. 기존4개96,344삼각형을 합쳐 시험 액터5개100,344삼각형이다. 정점에 월드 자세가 들어 있다.
- 전체 길이 약129.9m, 중앙 보행 폭3m/시각 폭5m, 실제 상면 삼각형 최대 경사43.06°다. 모서리/받침·암석 실루엣·몸체 캡과 재질은 후속 다듬기 대상이다. 충돌/보행 완료로 판정하지 않았다.

`Comparison.html`의 주황 테두리가 새 연결1개다. 남쪽 기존 대지 → 기존 경사로 시작 근처 → 몸체 옆 고가 구간 → 북쪽 회전부 → 기존 북쪽 지형으로 합류한다. 기존 지형을 이동해 재사용한 것이 아니라 새 연결의 양 끝을 기존 표면에 맞춘 것이다.

## 2. 형상과 접속 보정

초기 조사 중심선은 최대37°였지만 폭을 적용하니 코너 안쪽이56°까지 가팔랐다. 좁은 회전부의 높이/폭을 보정하고, 채택 북쪽 디딤면 바위와 가까운 동쪽 안을 피했다. 첫 시각 후보V008을 실제로 보니 남쪽 시작이 보이지 않는 기존 충돌용 Floor 위여서 떠 보였다. 이를 보이는 지각의 평탄 접속점까지 연장했다. 입력 높이장이나 충돌 프록시의 접촉만으로 시각 연결을 확정하지 않았다.

최종 남쪽 중심은 옥탄트 로컬 `(-7200,-4800,H약3806.6)`, 북쪽 중심은 `(-7200,2800,H약846.1)`이다. 원래 보여준 북쪽 후보 주변에서3m 폭과 기존 바위를 피하도록 조정했다. 남쪽 실제 지각과의 거리는3.2~6.8cm, 북쪽 잔존 구조 표면과는 약5cm다. 남쪽 가장자리1점의 ray 경계 누락은 같은 실제 정점의 최근접 지각 면으로 대조했고, 옆 방향 오차0.2cm 미만을 기록했다. `VisibleStartNearest.json`·GeometryCheck의 query 필드를 함께 읽는다.

`BuildRidgeConnectionTrial.py`는 보존된 원본 덤프·Cull 결정·fallback 형상과 기존 지각/보존 구조물을 읽기만 했다. 기존 배치/몸체 생성기·Cull·충돌/베이크를 재실행하지 않았다. 오프라인 V001~V007·V009~V010은 미반입 후보이며, UE에는 첫 시각 후보V008과 최종V011만 반입했다. V008 초기 맵/저작본/자세 기록은 `Geometry_V008/ActualDraft/`와 해당 새 메시 에셋으로 보존했다. 채택본을 덮어쓰지 않았다.

## 3. 통로·보호 공간과 남은 REVIEW

기존51보호 공간·16,552표본은 그대로 보존했다. 새 연결의 닫힌 부피 검사는 기존 StairRamp3에1표본만 추가 겹침이며, 나머지50공간(통로·Pod·동굴·석교·부유섬·그래플 사선 포함)은 새 겹침0이다. 기존4몸체의 StairRamp3 겹침28표본과 합쳐 **기존 경로29표본 REVIEW**다. 보호 폭을 줄이거나 기존 길을 검사 입력에서 삭제하지 않았다.

대체 연결의 별도 통로는10cm 간격·실제 miter 단면 중앙3m·위100/170/250cm의 **12,726표본**으로 검사했다. 잔존 구조 메시의 보수적 BVH 거리와 경계 후보의 실제 월드 삼각형 거리, 기존 지각·보존 Floor/Shell·몸체4개·연결 자체를 대조했다. 표면50cm 미만 근접0·닫힌 몸체 내부0·자기 교차 후보0이고 최소 거리 하한은 약71.96cm다. 원래 바위의 열린 외피 내부·연속 캡슐 이동·실제 보행/점프/그래플을 보증하는 검사는 아니다.

이전 기존길의 겹침을 새 연결의 통로 통과로 숨기지 않았다. 새 연결을 사용자 시각 검토한 뒤 대체 경로/기존 경로의 역할을 정하고, 같은 몸체 입력에서 충돌·내부 지각/Support·베이크·PIE로 이어간다. 현 시점은 NoCollision 초안이다.

새 메시의 최소 seam 거리는 약83.64m다. 시각 seam5m·후속 충돌20m 금지, 지각 native15m/전이55m, Floor50㎡·전체 Nav Layer256·산괴 배경A안 계약과 외곽 장식 종료/내부 보라 구조물·부유섬 후속 범위를 유지한다.

## 4. 실제 에디터 검사와 경고

`StaticMeshTools.import_file`이 등록된 것을 확인해 새 FBX만 MCP로 반입했다. 임의 UE Python은 Programmatic에서 실행하지 않았고, 전체 기존 지문 재검사만 사용자 Cmd의 `RidgeClosedBodyTrial.py verify V004`로 확인했다. 같은 이름의 `import V004`는 실행하지 않는다. 이 판은 기존4액터를 복제한 뒤 새1개만 MCP로 추가했기 때문이다.

새 컴포넌트의 `bUseDefaultCollision=true`이면 BodyInstance 값이 기본 충돌로 되돌아가는 것을 실제 조회로 확인했다. 새 연결에만 이를false로 바꾸고 `collisionEnabled=NoCollision`/프로필NoCollision을 설정한 뒤 실제 값을 재조회·지정 저장했다. 기존 충돌은 변경하지 않았다.

최종 `Verify_20261125_165639_785717.json`은 preservation_pass=true·issues없음·전체 dirty없음이다. 기존 Z1은185,555인스턴스·데칼12·428키와 SHA `853681a3ea1bdb4c002491d0ef4dd484f1723dac18a1915a7d61e8d027527b88` 그대로다. 기존8메시/Cull15개·채택21개 자세/참조/재질/지문, 몸체4개와 새 연결1개 실제 identity/메시/NoCollision/삼각형을 대조했다. Pod10·훅6·검토점27·LI/로드36개다.

기존200파일 해시는 불변이다. MCP로 이전25개 대비 실제26자세를 별도 export했고, 최종 FBX 범위 오차는0.05cm 미만·4,000삼각형이 일치했다. 새 메시 탄젠트/바이노멀 등 반입 경고는0이다. 속성 스키마 조회의 delegate 미지원 LogJson21건과 기존 Z1 Shell459,537삼각형의 에디터 Nav geometry export 경고2건은 따로 기록했다. 기존 Shell 액터/에셋을 변경하거나 전체 Support Atlas/Nav 베이크를 실행한 것은 아니다. 로그는 지우지 않았다.

## 5. 검토·복구와 다음 단위

근거 루트는 `Saved/Profiling/Graphics/Phase01/U5a_3_V001/`다. Comparison.html은 기존16+연결6의22시점 같은 카메라(위치/회전0.001 이내·FOV90°·1127×724) 전후 화면과 전체/사선 선택2화면·저작선 도식을 포함한다. 픽셀 동일성을 배치 보존으로 판정하지 않는다.

`FinalValidation_V001.json`·FinalReviewHashes.json·FinalDraft/는 최종 실제 검사/자세·새 맵/메시·저작/스크립트16파일 복구본을 소유한다. 추가 촬영/입력 형상 해시는 ReviewEvidenceHashes.json으로 구별한다. 저작 기준은 `ClosedBodyTrial_V001/Generation_V004.json`이며 이전 V003과 받아들인 U4Layout_V011은 변경하지 않았다.

에디터는 V004·PIE=false·맵 dirty=false, 새 연결 선택 상태와 마지막 사용자 시점을 유지했다. 전체 경로 선택 화면은 별도 저장했다. 현재 구현 단위의 배치/검사는 마쳤으며 **사용자 시각 채택을 기다린다.** 다음은 이 동선을 유지할지 검토하고, 유지하면 새 연결의 석재 형상/모서리/받침과 몸체 캡·재질을 다듬는 단위다. 충돌·지각/Support·베이크·PIE·세부 식생/잔돌은 아직 후속이다.

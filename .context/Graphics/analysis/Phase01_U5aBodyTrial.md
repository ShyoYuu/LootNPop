# Phase 1-BR U5a-1 닫힌 몸체 생성 시험

현재 최신 기준은 사용자 유지 **U5aBody_V006**이며 다음 U5a-6은 새 세션으로 넘겼다. [현재 인수인계](Phase01_U5aBodyHandoff.md)를 우선하고 아래 수치/대기 상태는 당시 시험 이력으로 읽는다.

최신 후속은 [U5a-3 연결 초안 결과](Phase01_U5aConnectionTrial.md)다. V004의 실제 보존/22비교를 마쳤고 사용자 시각 채택 대기다. 아래 내용은 이전 몸체 시험 기록으로 보존한다.

> 상태: 첫 생성·반입·보존/비교 검사 완료 · U5a 전체 미완료 · 경사로 겹침 REVIEW·미채택
> 확인: 2026-11-25
> 기준: GX-034~036 · [Phase U5a](../phases/Phase01_RidgeReferencePatch.md) · [이전 입력 조사](Phase01_U4LargeLayoutPlan.md) §19

최신 작업은 [U5a-2 경계 보정 진행](Phase01_U5aBodyRefinement.md)이다. 아래 V002는 이전 실제 검사 완료·미채택 보존본이며, 새 V003/생성V007은 실제 보존·16비교를 마쳤고 외관/경사로 REVIEW·수동 착지점 대기다.

## 1. 현재 결과와 다음 단위

사용자가 R01/R05 열린 외피와 R03/R04 하부 공동의 몸체 생성 시험 진행을 승인했다. 채택 U4Layout_V011은 동결한 채 새 시험 맵 두 판을 만들었다. 현재 검토본은 **U5aBody_V002, 생성 메시 판은 V006**이다. 맵 판과 오프라인 생성 메시 판을 구분한다.

네 몸체는 경계 변·비다양체 변 0이며 실제 반입·기존 Z1/채택21소유자 보존 검사를 통과했다. R03/R04 기록 위치는 같은 닫힌 몸체 부피에 들어간다. 다만 기존 `StairRamp3CentralPassage` 중앙 띠의32표본과 몸체 부피가 겹치므로 **미채택 REVIEW**다. 경사로 보호 폭을 줄여 통과시키지 않았다.

다음 단위는 **공동 몸체 경계/외관 다듬기와 StairRamp3 별도 연결 검토**다. 몸체를 보존하는 서쪽 우회 연결 도식을 제안으로 남겼으며 아직 길을 배치하거나 높이·기존 암석/동굴·통행을 검증하지 않았다. 기존 큰 배치를 옮기거나 개별 삭제하지 않는다. 새 몸체의 충돌·내부 지각/Support 제거·베이크·수동 접근 PIE와 다른 구역 확대는 후속이다.

## 3. 생성 방식과 시험 경과

새 `Scripts/Blender/BuildRidgeClosedBodyTrial.py`가 기존 Cull 이전 덤프를 당시 제외 결정으로 읽기 전용 대조한다. 잔존185,555개만 사용하며 원본 생성기·Cull·기존 프록시를 다시 실행하지 않는다. 고유 fallback 메시 이진 파일은 보존한 Export_V037에서 해시를 확인해 읽었다. 이 과거 입력 조사를 새 live geometry export로 표시하지 않는다.

정확한 지적 노출 면의 메시 동일성은 아직 확정하지 않았다. R01/R05의 알려진 후보를 시험했으며 R02/R06은 회귀 감시 대상으로 남긴다. 기록점이 몸체 안에 들어간 결과도 구멍 전체의 시각/물리 진입 차단을 보증하지 않는다.

초기 경계 cap만으로는 넓은 하부 공동을 채우지 못했다. 가장 높은 표면을 지면까지 내린 후보V004는 하부 몸체 약2,271m³·26,208삼각형과 경사로44겹침을 만들었고 큰 벽처럼 보이는 구간이 있었다. 가까운 천장과 공동 주변으로 제한한 V006에서 하부 부피를 약564m³·8,000삼각형, 경사로 겹침을32표본으로 줄였다. 오프라인 V001~V005는 중간 시험 기록이며 UE에는 생성V004/V006만 반입했다.

캡은 아직 평면감과 UV/외피 연결 다듬기가 필요한 시각 초안이다. 원래 ED 외피의 메시·배치·내부 식생은 수정하지 않았다. 단일 큰 볼록 껍질이나 양면 표시/투명 충돌만으로 해결하지 않았다. 이웃 동굴·교량 아래의 의도된 공간도 몸체 전체로 메우지 않았다.

- 기존 Z1 지문은185,555인스턴스·데칼12·428키, SHA-256 `853681a3ea1bdb4c002491d0ef4dd484f1723dac18a1915a7d61e8d027527b88` 그대로다. 기존 메시8개 자세/참조/재질/프로필, Cull LI15개 자세/참조, 채택21개 자세/참조/지문을 대조했다.

촬영 초기에 V002 `ComparisonCameras.json`을 복사하기 전에 읽어 `File not found`가 한 번 출력됐다. **에이전트의 파일 준비 순서 오류**이며 해당 파일을 복사한 뒤 같은 촬영을 성공시켜16시점을 완료했다. 읽기 실패는 맵/반입 상태에 영향을 주지 않았다. 별도 촬영1회는 자동 승인 검토 시간 초과였고 허용된1회 재시도에서 성공했다. Blender의 선택적 사용자 썸네일 캐시 쓰기 거부는 메시/FBX 출력에 영향을 주지 않았다. 이 경위는 WarningReview.json에 구분해 남겼고 Output Log는 지우지 않았다.

## 5. 보호 공간과 남은 REVIEW

기존51개 공간·16,552표본의 **닫힌 몸체 부피** 검사를 했다. 이전 메시 상자 검사를 이번 몸체 부피 검사와 혼용하지 않는다. Cave/Pod/석교/부유섬/그래플 등 나머지50공간의 표본 겹침은0이다. `StairRamp3CentralPassage`만32표본이 하부 몸체 부피에 들어간다.

기존 경사로는 `(-8500,-3600,H약3773)→(-7000,2400,H600)` 중앙3m 띠다. R03 기록점이 이 중앙 띠 부근이므로 공동을 채우는 작업과 현재 길의 연결을 함께 다뤄야 한다. 몸체 상단 높이만 같은 선으로 따라 올리는 방식은 일부 표본에서 현재 지면보다 약22.79m 높아 적합성이 미확정이다. 이 수치는 몸체 상단 단면이며 정확한 보행 차단 길이나 물리 통과 판정이 아니다.

`StairRamp3Plan.svg`의 서쪽 우회 점선은 다음 단위의 검토안일 뿐 새 확정 경로가 아니다. 지형 높이·기존 암석·동굴·시야·연결 경사를 조사하고, 미채택 몸체 경계 보정 또는 별도 연결로 해결한다(GX-035). 입력 보호 폭을 축소하거나 겹침을 숨기지 않는다.

충돌 역할(Crust/Floor/Shell), 내부 지각/Support 제거·Floor50㎡·전체 Nav Layer256·산괴 배경 A안·빠진 Pod2개 제외·실제 보행/점프/그래플 검증은 후속이다. 현재 새 몸체는 NoCollision이므로 이 시험 맵으로 기존 베이크나 현재 몸체의 통행 안전을 판정하지 않는다. 몸체와 연결이 정리된 뒤 같은 입력에서 충돌/지각을 파생하고 필요한 범위를 사용자 수동 PIE로 확인한다.

## 6. 비교·복구와 이어서 할 일

근거 루트는 `Saved/Profiling/Graphics/Phase01/U5a_1_V002/`다. `Comparison.html`은 기존8+지적/경사로8의16시점, Unlit/FOV90°/1127×724 전후 비교다. 이전 화면은 몸체가 없던 V011 사본에서 촬영한 `U5a_1_V001/Views_Before/`다. 위치/회전0.001°/cm 이내·FOV/크기 대조는 PASS이며 이미지 픽셀 해시 일치를 요구하지 않았다.

`FinalValidation_V001.json`·FinalReviewHashes.json·FinalDraft/는 실제 자세 기록·보존 검사·현재4메시/맵·저작본/스크립트 복구본을 소유한다. 생성 형상·GeometryCheck·SurfaceFit·StairRamp3Profile은 `U5aBody_V006/`에 있고 이전 후보도 각 버전 폴더에 보존했다. 저작 입력은 `ClosedBodyTrial_V001/BodyTrial.json`(U5a-0 고정 스냅샷), 현재 생성/반입 기준은 같은 폴더 `Generation_V002.json`이다.

에디터에는 `U5aBody_V002`·PIE=false·dirty없음, 하부 몸체 선택과 UnderVoidOverview를 남겼다. 사용자가 바꾼 상태는 다음 시작 때 다시 읽는다. 현재 후보는 미채택이며 U5a 전체 완료가 아니다. 다음 구현 단위의 몸체 경계/외관 다듬기·StairRamp3 별도 연결 방향을 확인한 뒤 진행한다.

## 1. 이번 세션의 종료 지점

- 사용자가 V010 PIE 제보 수집을 **R01~R06에서 종료**하고, 전체 큰 배치를 새 세션에서 진행하도록 지시했다. 제보 수집을 계속하는 단계가 아니다.
- 사용자는 현재 전반적인 비주얼과 산·절벽·큰 바위의 배치를 채택했다. 위치·방향·크기·높이 관계·스카이라인·주요 구도를 보존한다. 열린 외피 뒤·아래의 몸체와 지면 받침은 이후 이 배치를 기준으로 만든다. 국소 이음·잔돌·식생은 조정할 수 있다.
- 다음은 **U4 전체 큰 배치 초벌**이다. 미배치 구역의 큰 지형과 주요 통로 관계를 채우고 구역별 배치 JSON을 확정한다. 세부 식생·잔돌 마감과 몸체·충돌 재빌드는 지금 시작하지 않는다.
- 이번 세션에서는 문서·제보 기록·복구만 수행했다. V037 배치 JSON·시각/충돌 에셋은 수정하지 않았다. U6 시각·동선 게이트를 통과한 것은 아니며 NPC 전투도 확인하지 않았다.

## 4. 새 세션의 첫 단위

**아래 U4-0은 2026-11-24에 완료했다.** 실제 조사·보존 목록·복구/비교 근거와 후속 단위의 원본은 [U4 큰 배치 계획](Phase01_U4LargeLayoutPlan.md)이다. 배치는 바꾸지 않았으며 다음은 그 문서 §5의 U4-1 진행 확인이다. 아래 시작 절차와 §6 프롬프트는 이 작업을 시작한 이전 인계 기록이다.

**U4-0: 현재 큰 배치 보존 목록과 전체 미배치 구역 계획을 구체화한다.**

1. 필수 문서와 GX-034를 읽고 실제 에디터·파일 상태를 대조한다. 사용자의 미저장 변경은 임의 저장·폐기하지 않는다.
2. V037의 큰 조립체·CR 산괴·주요 바위와 지형 윤곽을 보존 대상으로 정리하고, transform·입력 지문·대표 부감/분지/테두리 시점의 비교 기준을 확보한다. 대규모 배치 변경 전 복구 사본을 마련한다.
3. Z1~Z7의 실제 배치 여부와 부족한 큰 덩어리를 구분한다. 현재 알려진 미완성 범위는 Z2 석교 아래 협곡 바닥, 남 테두리 위 남쪽 대지·협곡 남벽, 북쪽 단 뒤 오름 사면 등이다. 이 목록만으로 나머지가 완성됐다고 간주하지 않는다. 동굴 지붕 아래 동쪽 사면·NorthLedge는 보존 구조물의 다음 교체 패스와 범위를 구분한다.
4. 구역별 큰 덩어리·높이·주요 통로와 인접 구역 연결을 제안하고 첫 배치 단위를 정한다. 구현 단위가 끝나면 결과와 다음 진행을 확인한다.

이어지는 U4 배치에서는 기존 Z1의 큰 구도와 덩어리를 유지하며 미배치 구역을 채운다. ED 조립체·산괴·둑 사용 방식은 확정 결정과 현재 팔레트를 따른다. 원본 ED 조작·Migrate·저장·육안 판정 등 수동이 더 효율적인 단계는 즉시 사용자에게 요청한다. 몸체를 나중에 만들 수 있도록 의도된 동굴·석교 아래·실제 이동 통로와 메워야 할 내부를 구역별로 기록한다.

## 5. 제보와 후속 단계

제보의 좌표·증상·사진 연결 원본은 [Phase 로그의 이번 PIE 제보 대장](../history/Phase01_Log.md)이다. R01/R05는 열린 절벽 계열 외피, R02는 큰 개구부 진입, R03/R04는 같은 하부 공동의 서로 다른 입구, R06은 구멍으로 내려가 외피 뒤에 도달한 사례다. **R06 내부 정면은 충돌이 있는 벽이며 추가 통과구가 아니다.**

- R01/R05에 동일 메시 배치가 존재함은 확인했지만, 지적한 모든 면이 같은 메시인지는 미확정이다.
- 이번 6건을 개별 Cull 삭제·투명 충돌벽으로 먼저 처리하지 않는다. 현재 큰 배치를 보존한 몸체 단계의 입력·재검증 지점으로 넘긴다.
- 순서: **U4 전체 큰 배치 초벌·구역별 확정 → U5a Z1 몸체 시험 → U5b 구역별 몸체·충돌 → U6 전체 베이크/PIE → U7 세부 마감**.
- 산괴의 적 Nav 밖 배경(A안)·빠진 Pod 2개·동선 보호 보류는 몸체 추가만으로 변경하지 않는다. 이음매·구면 Up·충돌 역할·Floor 50㎡·Nav Layer 예산·패키지 성능 판정 원칙도 유지한다.
- 알려진 설계 보류는 Crown 검토점·CrownSouthRimAnchor/Terrace3Hub, WestStairAscent/CrownToSaddle, 석교 북단(갑판 38.4m와 고원 약 6m 사이 단절)이다. NorthSaddle의 같은-Layer 후보는 7개(편성 27명), SouthMesa는 20개였고 전투 검증은 미실시다. 이 항목들을 현재 큰 배치를 되돌리는 근거로 삼지 말고 전체 배치·후속 몸체와 마커 검토에 넘긴다.
- `DeepBasin → LandmarkTop` 사선 대상은 현재 산괴 기준 재정의가 필요하다. 벽 발치 잔돌 판과 빈 분지 바닥의 세부 장식은 U7로 넘긴다.

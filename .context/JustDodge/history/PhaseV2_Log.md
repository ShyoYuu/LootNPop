# V2 — 고정 포즈 잔상 작업 기록

## 2026-11-05 — 조사·사용자 설계 검토·구현

- 사용자가 V2 진행을 요청한 뒤 구현 전에 상세 설명을 요구했다. 당시에는 코드·에셋을 변경하지 않고 포즈 복사 API와 기존 머티리얼을 조사했다. 기존 후보는 파티클 UV·ParticleColor에 의존해 전신 잔상에 직접 재사용하기 어려웠다.
- 사용자는 전용 액터의 비용을 우려했다. 캐릭터 소유 PoseableMesh 한 세트 재사용·Tick 제거·머티리얼 시간 페이드로 변경하는 안을 설명했고, 넉백 중에도 잔상이 고정되는 구조를 설명한 뒤 구현 승인을 받았다. 몸용 하나와 표시 무기용 하나라는 구성을 명시했다. J-023에 기록했다.
- `ALNPCharacterBase`에 첫 사용 때 만드는 몸·무기 잔상, 공유 MID와 종료 타이머를 추가했다. 루트·메시에 부착하지 않고 `CopyPoseFromSkeletalComponent`로 한 번 복사한 뒤 직접 뼈 변환을 갱신한다. 컴포넌트 Tick·충돌·겹침·그림자·데칼을 끈다. 0.35초 뒤 숨기며 재사용한다. 순보 숨김 중 재진입은 기존 스냅샷을 덮어쓰지 않는다. EndPlay에서 타이머를 정리한다.
- 성공 큐에 `AfterimageMaterial` 참조를 추가하고 기존 순보 함수로 전달한다. 순보로 원본을 숨기기 전에 잔상을 만든다. 판정·이동·버프·원격 방향 수정과 기존 Niagara 시스템은 변경하지 않았다.
- 현재 세션 도구 목록에 Unreal MCP가 없어 프로젝트 `.mcp.json`의 로컬 8000번 HTTP 연결을 사용했다. Initialize와 읽기 도구 호출로 라이브 에디터를 확인하고 Agent Skills의 머티리얼·Blueprint 규칙을 읽었다. PIE=false를 확인했다.
- 작업 대상 성공 큐만 먼저 저장한 뒤 `/Game/Effects/Combat/M_JustDodge_Afterimage`를 생성했다. 표준 노드 15개·연결 14개로 게임 시간 페이드와 무채색 프레넬을 구성했다. 도구 재컴파일이 성공했고 Unlit·Translucent·twoSided=false·bUsedWithSkeletalMesh=true를 다시 읽어 확인했다. Time은 일시정지를 따르며 주기 반복은 껐다. 수명 기본값 0.35도 재조회했다.
- 시작 수치는 비주얼 설계 §2.2에 기록했다. 새 머티리얼과 성공 큐만 경로를 지정해 저장했고 성공했다. 성공 큐의 새 참조 연결은 C++ 재시작 뒤에 한다. 실제 출력·페이드·월드 고정은 아직 검증하지 않았다.
- 사용자에게 저장·에디터 종료를 요청하고 완료 확인을 받았다. 권한 확장으로 `LootNPopEditor Win64 Development` 전체 빌드를 `-WaitMutex -NoHotReloadFromIDE -DisableAdaptiveUnity`로 실행 중이다. `git diff --check`를 통과했다. 빌드 결과·큐 연결·사용자 검증은 후속 기록에 남긴다.

## 2026-11-05 — 전체 빌드 통과

- 사용자 에디터 종료 확인 뒤 실행한 전체 빌드가 성공했다. UHT는 9개 생성 파일을 갱신했고, 9개 unity 소스·라이브러리·DLL·메타데이터 12개 작업을 마쳤다. `Result: Succeeded`, 종료 코드 0, 103.62초다. 다른 작업 변경이 있어 깨끗한 트리 빌드는 아니다.
- 사용자 PIE 평가와 성공 큐 참조 연결을 위해 프로젝트 에디터를 다시 실행했다. 아직 큐의 새 참조 연결·런타임 출력은 확인하지 않았다.

## 2026-11-05 — 큐 연결·저장·사용자 검증 요청

- 에디터 재시작 뒤 MCP 세션을 새로 열고 `IsPIERunning=false`로 읽기 연결을 확인했다. 성공 큐의 새 `afterimageMaterial` 속성이 존재하고 초기값 None인 것을 읽은 뒤 새 머티리얼을 지정했다.
- 성공 큐는 경고를 오류로 취급해 컴파일했고 성공했다. 머티리얼도 재컴파일했다. 성공 큐와 새 머티리얼 두 에셋만 지정해 저장했고 성공했다. 다시 읽은 큐 참조는 새 머티리얼과 기존 사라짐·나타남 Niagara 두 개를 정확히 가리킨다.
- 저장·재시작 뒤 머티리얼 출력 연결을 읽어 Emissive=색 보간, Opacity=알파×페이드임을 확인했다. Time은 일시정지를 따르고 주기 반복이 없으며 Duration=0.35, 프레넬 지수 4·기본 반사율 0.02도 유지됐다.
- `git diff --check`를 통과했다. V2 에셋 변경은 기존 성공 큐 하나와 새 잔상 머티리얼 하나이며 기존 두 Niagara 시스템은 변경하지 않았다.
- 사용자에게 미리보기 1로 몸·무기·맨손·방향별 고정 포즈·밝기·0.35초 페이드를 평가하고, 미리보기 0으로 양방향 실제 성공과 무적 만료 뒤 넉백 중에도 잔상이 고정되는지 확인하도록 요청했다. 짧은 넉백 구간을 재현하지 못하면 미확인으로 구분한다. 현재 결과 대기 중이다.

## 2026-11-05 — 사용자 무기 교체·양방향 출력 확인

- 사용자는 여러 무기를 교체하며 대시해도 잔상에 잘 반영되는 것을 확인했다. 여러 적과의 난전 속에서도 잔상이 꽤 안정적으로 유지된다고 보고했으며, 호스트·게스트 화면에서 상대 캐릭터 잔상이 잘 보이는 것도 확인했다.
- 잔상이 남아 있는 동안 정확히 피격되는 순간은 확신하지 못한다고 했다. 따라서 무적 만료 뒤 잔상 수명 안의 넉백·물리 피격 반응이라는 개별 경계는 런타임 미확인으로 남긴다. 난전 안정성 관찰과 코드 검토만으로 이 항목까지 통과로 표시하지 않는다.
- 로그에는 미리보기 1 입력(`13:36:55 UTC`, 한국 시각 22:36:55)과 0 전환(`13:41:26 UTC`, 한국 시각 22:41:26)이 남아 있다. 판정 디버그가 꺼져 있어 이번 실제 성공·큐 도착 건수는 집계하지 않았고, 원격 출력은 사용자 관찰을 근거로 기록한다.
- 밝기·형태·0.35초 수명의 별도 변경 요청이나 선호 평가는 없었다. 현행 구현·수치를 유지하고 기본 출력·무기 교체·양방향 관찰의 주요 검증을 정리했다. 이번 결과 반영에서는 코드·에셋 변경이나 추가 빌드를 하지 않았다.
- 다음 단위는 V3a 카메라·부착 오라다. ADS FOV와 FOV 펀치 우선순위를 먼저 확인하고, 조사 결과·구체 구현안을 설명한 뒤 진행한다.

## 2026-11-05 — 세션 마감·새 세션 인계

- 사용자가 다음 작업은 새 세션으로 넘기고, 인수인계를 포함한 문서를 갱신한 뒤 이번 작업을 한 번에 커밋하도록 요청했다. V3a 구현은 시작하지 않았다.
- `Current.md`에 다음 세션 필수 문서·카메라/ADS/버프 큐 조사 경로와 구현 전 설명 절차를 남겼다. ADS 중 FOV 펀치 생략은 에이전트 제안이며 사용자 확정이 없다는 점을 명시했다. V1a·V2의 미확인 경계, 보정 비교 미측정, 밝기·수명 별도 선호 미보고도 유지했다.
- 공통 기획·기술 요약과 DevelopmentPlan의 비주얼 상태를 실제 구현에 맞췄다. 기존 커밋의 `feat:` 접두어·한국어 요약 형식을 확인했으며, 이번 커밋 범위는 순보 방향 수정·잔상 코드/에셋·관련 문서다. 세션 시작 때부터 있던 엘리트 NPC·부위별 데미지·공통 인덱스 변경은 이번 작업 범위에 포함하지 않는다.
- V2 전체 unity 빌드·BP/머티리얼 컴파일과 대상 저장은 앞선 기록대로 성공했다. 커밋 후 `-DisableAdaptiveUnity` 빌드 확인은 최종 응답에 결과를 보고한다. 별도 작업 문서 변경이 남아 있으므로 전체 작업 트리가 깨끗하다고 기록하지 않는다.

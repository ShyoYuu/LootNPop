# 저스트 회피 검증 규약

> 상태: 기준 설계
> 마지막 갱신: 2026-10-26

## 1. 실행 환경

| 환경 | 용도 |
|:---|:---|
| PIE 1인 (TestMap03) | 경로별 기본 동작 |
| PIE 리슨 2인 | 게스트 대시가 서버 판정을 받는지, 관전자 화면, 보정 캡슐 |
| PIE 리슨 2인 + 네트워크 에뮬레이션 (`PktLag` 50/100) | 지연 체감, J-007·J-010 재검토 (Phase 3) |

- 적의 공격을 재현할 편성: 기본 `DA_MassSpawnConfig`는 그대로 두고, 검증 편성 에셋에 `LNP.Spawn.ConfigOverride`를 걸어 쓴다. 근접·원거리(직선·포물선)·폭발 투사체를 쓰는 종을 포함한다.
- 화염 경로는 두 번째 플레이어가 화염방사기로 쏘는 PvP로 재현한다(다른 팀 설정 필요).
- 사용자 플레이 테스트는 한 번에 정보를 많이 얻도록 시나리오를 요인설계로 묶어 요청한다.

## 2. 공통 회귀 (모든 Phase)

- 가드·패링(근접·투사체 반사)이 기존대로 동작한다. 대시하지 않으면 결과가 이전과 같아야 한다.
- 대시하지 않은 일반 피격·경직·넉백이 그대로다.
- 대시 이동, 대시 점프, 쿨다운 HUD 파이가 그대로다.
- 리슨 2인에서 대시할 때 보정 캡슐이 늘지 않는다(`mover.debug.ShowCorrections 1`, 필요하면 `LNP.Spawn.EnemyDensity 0`).
- 깨끗한 트리에서 Build.bat이 통과한다.

## 3. 무적 시나리오 (Phase 1)

| ID | 시나리오 | 기대 결과 |
|:---|:---|:---|
| D-01 | 적 근접 공격이 닿기 직전 대시 | 피해·경직·피격 큐 없음, 서버 로그 `[Dodge] IFrame ignored path=Melee` |
| D-02 | 너무 일찍 대시해 무적이 끝났는데도 칼날 안에 남음 | 그 휘두르기에 맞는다 |
| D-03 | 직선 투사체가 무적 중인 플레이어를 지남 | 탄이 사라지지 않고 관통해 뒤의 대상(다른 플레이어·지형)에 맞는다 |
| D-04 | D-03 직후 무적이 끝난 상태에서 같은 탄이 다시 겹침 | 다시 맞지 않는다(회피 대상 칸) |
| D-05 | 폭발 반경 안에서 무적 중 | 피해·넉백·경직 없음 (`path=Splash`) |
| D-06 | 화염 원뿔 안에서 무적 중 | 무적 동안 틱 피해·화상 스택 없음, 무적이 끝나면 다시 들어온다 (`path=Flame`) |
| D-07 | 게스트가 D-01·D-03 수행 | 서버 판정으로 무적 적용, 게스트 화면에 예측 임팩트가 남지 않는다 |
| D-08 | 무적 중 사망 직전 상황 → 리스폰 후 첫 피격 | 리스폰 직후 무적이 남아 있지 않다 |

## 4. 저스트 회피 시나리오 (Phase 2)

| ID | 시나리오 | 기대 결과 |
|:---|:---|:---|
| J-01 | 근접 공격이 패링 반경에 들어오는 순간 대시 | `[Dodge] JustDodge success attack=Melee`, 디버그 텍스트, 버프 적용 |
| J-02 | 투사체 직격이 지나가는 순간 대시 | 성공 + 관통 |
| J-03 | 폭발·화염 안에서 대시 | 무적만 적용, 저스트 회피 없음 (J-002) |
| J-04 | 적 여럿이 동시에 공격하는 중에 한 번 대시 | 성공 로그 1건 (J-011) |
| J-05 | 2.5초 안에 저스트 회피 연속 2회 | `LNP.Debug.ShowSpeed`의 MoveSpeed가 x1.20에서 늘지 않고, 만료가 마지막 성공 + 2.5초 |
| J-06 | 버프 중 스탯 탭 확인 | AttackSpeed·MoveSpeed 곱연산 칸에 +20% 표기 |
| J-07 | 버프 중 근접 공격 속도 | 다음 몽타주부터 빨라진다 |
| J-08 | 게스트가 J-01, J-05 수행 | 서버에서 버프 적용, 버프 경계에서 보정 캡슐이 체감되지 않는다 |
| J-09 | 등 뒤에서 오는 공격에 저스트 회피 | 성공한다(각도 조건 없음, J-004) |

## 5. 비주얼 시나리오 (트랙 V)

| ID | 시나리오 | 기대 결과 |
|:---|:---|:---|
| V-01 | 호스트가 저스트 회피, 게스트가 관전 | 게스트 화면에 사라짐·잔상·나타남이 보이고, 그 뒤 오라가 보인다 |
| V-02 | 게스트가 저스트 회피 | 화면 연출(그래픽스 레이어가 생긴 뒤)과 쉐이크는 게스트 본인에게만 나온다 |
| V-03 | 이미터 실제 출력 | 원점에서 먼 위치에서 Niagara 픽셀이 실제로 그려진다(PIE 스크린샷으로 확인) |
| V-04 | 버프 갱신 중 오라 | 꺼졌다 켜지지 않고 유지되며, 만료 시 사라진다 |
| V-05 | 네트워크 에뮬레이션 100ms에서 소유 화면 | 순보가 "빠져나갔다"로 읽히는지 사용자 판정 |

## 6. 로그 판정 문자열

| 문자열 | 의미 |
|:---|:---|
| `[Dodge] IFrame ignored path=<Melee\|Projectile\|Splash\|Flame>` | 무적으로 무시한 피격 (서버) |
| `[Dodge] JustDodge success player=<id> attack=<Melee\|Projectile>` | 저스트 회피 성공 (서버) |
| `[Guard] Block success` | 기존 가드 로그 — 회귀 확인용 |

# 저스트 회피 확정 결정

> 상태: 확정 결정 원장
> 마지막 갱신: 2026-10-26
> 규칙: 결론만 기록하고, 상세 근거와 구현은 링크된 문서가 소유한다. ID 접두어 `J-`는 다른 작업 폴더의 `D-`·`L-`와 구분하기 위한 것이다.

## 결정 목록

| ID | 결정 | 상태 | 상세 근거 |
|:---|:---|:---|:---|
| J-001 | 회피 상태는 `ExecuteDash`의 비리시뮬레이션 분기(권위·오토노머스)에서 `FLNPParryStateFragment`에 만료 시각으로 미러링한다. 판정은 `LNPGuardParry::Judge` 한 곳에서만 한다. 경로별로 분기를 복제하지 않는다 | 확정 | `design/Architecture.md` §2·§3, [HitDetection §7.5](../TechDesign_HitDetection.md) |
| J-002 | 저스트 회피는 근접과 투사체 직격에만 발동한다. 화염 틱과 스플래시는 무적만 적용한다. 기존의 `bInParryRange=false` 규약을 그대로 쓴다 | 확정(2026-10-26, 사용자) | `design/Architecture.md` §4 |
| J-003 | 무적 중인 플레이어를 지나는 투사체는 관통해 계속 날아간다. 같은 대상을 다시 맞히지 않는다(투사체에 회피 대상 1칸) | 확정(2026-10-26, 사용자) | `design/Architecture.md` §4 |
| J-004 | 저스트 회피 반경은 기존 `ParryRadius`를 재사용한다. 각도 조건은 없다(회피는 전방향) | 반경 확정(사용자) / 각도 초안 | `design/Architecture.md` §3 |
| J-005 | 버프는 AttackSpeed·MoveSpeed 곱연산 +20%, 2.5초다. 중첩되지 않고 시간만 갱신한다. C++ GE에 Burn 스택 패턴과 SetByCaller를 쓴다 | 확정(2026-10-26, 사용자), 수치는 튜닝 대상 | `design/Architecture.md` §5 |
| J-006 | 판정 순서는 패링 → 저스트 회피 → 무적(`Dodged`) → 가드 → 피격이다 | 초안 | `design/Architecture.md` §3 |
| J-007 | 판정은 서버 권위다. 연출은 서버 확정 뒤 GameplayCue로 전파한다. 소유 클라이언트의 연출 예측은 하지 않는다 | 초안 — Phase 3 지연 측정 후 재검토 | `design/Architecture.md` §6 |
| J-008 | 월드 전체 슬로모는 쓰지 않는다. 서버 시간을 모든 플레이어가 공유하기 때문이다. 슬로모 느낌은 로컬 화면 연출로 낸다 | 확정 | `design/VisualDesign.md` §2 |
| J-009 | 저스트 회피의 색 계열은 보라(바이올렛)다. 패링(청백), 가드(주황), 버프 주사위(초록)와 겹치지 않게 한다 | 초안 | `design/VisualDesign.md` §1 |
| J-010 | 대시 무적에 RTT 역보정을 하지 않는다. InputCmd 경로라 서버가 입력 프레임에서 대시를 실행한다 | 초안 — Phase 3 측정 후 재검토 | `design/Architecture.md` §6 |
| J-011 | 저스트 회피는 대시 한 번에 한 번만 발동한다. 같은 창 안에 공격이 여러 개 들어와도 첫 건만 인정한다 | 초안 | `design/Architecture.md` §3 |
| J-012 | 비주얼은 맨 마지막의 독립 트랙(V)으로 둔다. 메인 트랙과의 경계는 GameplayCue 태그 2개다. 로컬 화면 연출, 버프 림라이트, 원점에서 먼 Niagara 정밀도 조사는 그래픽스 작업으로 넘긴다. 잔상은 V에 남기고 비용 측정만 그래픽스 쪽에서 한다 | 확정(2026-10-26, 사용자) | `Roadmap.md` §4, `design/VisualDesign.md` §3 |

## 변경 규칙

- 확정 결정을 바꿀 때 기존 행을 조용히 덮어쓰지 않는다.
- 기존 행의 상태를 `대체됨`으로 바꾸고 새 ID를 추가한다.
- 변경 이유와 영향은 관련 설계 문서와 현재 Phase 로그에 기록한다.
- 단순한 구현 선택이나 임시 디버그 값은 이 원장에 넣지 않는다.

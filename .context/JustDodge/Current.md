# 저스트 회피 현재 작업 상태

> 상태: 활성 인계 문서
> 현재 작업: 메인 트랙 Phase 1 회피 무적 — 착수 전
> 마지막 갱신: 2026-10-26

## 현재 결정

**작업 계획 수립(2026-10-26).** 코드 변경은 아직 없다. 사용자가 정한 것은 다음과 같다.

- 저스트 회피는 근접 공격과 투사체 직격에만 발동한다(J-002).
- 무적 중인 플레이어를 지나는 투사체는 관통한다(J-003).
- 반경은 기존 패링 반경을 쓴다(J-004).
- 버프는 AttackSpeed·MoveSpeed 곱연산 +20%, 2.5초, 시간만 갱신한다(J-005).
- 비주얼은 마지막 독립 트랙으로 둔다. 화면 연출·림라이트·Niagara 정밀도 조사는 그래픽스 작업으로 넘긴다(J-012).

출발점(상세는 `design/Architecture.md` §1):

- 대시는 GAS 밖에 있다. InputCmd를 타고 Mover 시뮬레이션의 `ExecuteDash` 안에서 실행되며, 대시 상태를 나타내는 ASC 태그나 Mass 플래그는 없다.
- 무적 플래그는 프로젝트 어디에도 없다.
- 플레이어 피격 판정 4곳(근접·투사체 직격·스플래시·화염)은 모두 `LNPGuardParry::Judge` 하나를 부른다. 이 함수가 확장 지점이다.

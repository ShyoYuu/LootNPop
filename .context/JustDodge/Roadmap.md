# 저스트 회피 로드맵

> 상태: 기준 로드맵
> 읽기 조건: Phase 전환, 전체 순서 변경, 범위 재산정, 그래픽스 이관 항목 확인 시
> 마지막 갱신: 2026-11-05

## 1. 진행 원칙

- **메인 트랙(게임플레이)은 비주얼 없이 완결한다.** 성공 여부는 디버그 화면 텍스트로 확인한다.
- **비주얼 트랙(V)은 메인 트랙 뒤에 독립적으로 진행한다(J-012).** 메인 트랙 Phase 2의 연출 경계(큐 태그 2개 + 빈 GCN 에셋)만 있으면 시작할 수 있다. 그래픽스와 무관한 1차 단위를 먼저 하고, 그래픽스에 의존하는 2차 단위는 게이트가 열린 뒤 한다(J-020).
- 각 Phase는 따로 검증하고 커밋할 수 있어야 한다.
- 다음 Phase의 상세 실행서는 착수 직전에 쓴다.
- 모든 Phase의 완료 조건에 다음 두 가지를 넣는다.
  - `design/Validation.md` §2 공통 회귀(가드·패링, 일반 피격, 대시 이동·대시 점프, 2인 보정 캡슐)
  - 깨끗한 트리에서 Build.bat 통과

## 2. 단계 의존성

`Phase 1 회피 무적`
→ `Phase 2 저스트 회피 판정 + 버프 + 연출 경계`
→ `Phase 3 수치 1차 튜닝·지연 측정`
→ `Phase 4 피격 유예 버퍼(J-010 대응) + 문서 마감`

`비주얼 트랙 V`는 Phase 2 뒤라면 언제든 시작할 수 있다. [그래픽스 작업](../Graphics/README.md)과 엮이는 정도에 따라 두 묶음으로 나눈다(J-020, 2026-11-05).

- **1차(그래픽스 무관, 그래픽스 Phase 0보다 먼저):** `V1a 순보 핵심` → `V2 잔상` → `V3a 카메라·부착 오라` → `V4a 1차 체감 점검`
- **2차(그래픽스 게이트 뒤):** 아래 순서는 그래픽스 진행 순서를 따른다.
  - `단위 N` → `V3b 이동 꼬리·이미터 규칙 재확인`
  - `Phase 3-2` → `V5 화면 연출 트리거 연결`
  - `Phase 3-3` → `V6 나타남 오버레이 플래시·버프 림라이트`
  - V5·V6 뒤 → `V4b 최종 체감 튜닝`

전체 교차 순서는 다음과 같다: V1a → V2 → V3a → V4a → 그래픽스 Phase 0 → N → V3b → Phase 1 → Phase 2(잔상 비용 측정 포함) → 3-1 → 3-2·V5 → 3-3·V6 → V4b → 그래픽스 3-4 이후.

- V2를 그래픽스 Phase 2보다 먼저 끝내야 그쪽 측정 항목(잔상 반투명 비용)에 넣을 수 있다.
- V4a를 1차에 둔 이유: 지연 시 순보가 "빠져나갔다"로 읽히지 않으면 J-007(연출 예측 없음)을 다시 검토해야 한다. 메인 트랙 설계로 되돌아갈 수 있는 판단이라 일찍 한다.

## 4. Phase별 범위 보충

### Phase 1

이 Phase의 위험은 크게 두 가지다.

- **누락 경로:** `Judge`를 거치지 않고 플레이어에게 피해를 주는 경로가 있으면, 그 경로에서는 무적이 새어 나간다.
- **투사체 재피격:** 무적이 끝난 직후 같은 탄이 다시 맞는 경우다.

그래서 단위 0에서 피해 경로를 전수 조사한다. 상세는 Phase 문서가 소유한다.

### Phase 2

- 프래그먼트에 저스트 창 만료 시각과 소비 플래그를 추가하고, `Judge`에 `JustDodged`를 추가한다(`design/Architecture.md` §3).
- 투사체 직격 경로는 지금 `PS.bIsParrying`일 때만 패링 반경을 계산한다. 저스트 창이 열려 있을 때도 계산하도록 조건을 넓힌다.
- 성공 커맨드 `FLNPJustDodgeCommand`와 버프 GE `ULNPGameplayEffect_JustDodgeBuff`를 만든다(§5).
- **연출 경계:** 태그 `GameplayCue.LNP.JustDodge.Success`·`GameplayCue.LNP.JustDodge.Buff`를 정의하고 빈 GCN 에셋을 연결한다. 이 Phase에서는 비주얼을 만들지 않는다.
- `LNP.Debug.ShowDodge 1`일 때 성공 화면 텍스트를 띄운다(테스터 피드백용, Phase 1에서 화면 문구 CVar를 로그와 분리했다).
- 확인할 위험: MoveSpeed는 ASC에서 직접 읽기 때문에 버프가 켜지고 꺼지는 순간 보정이 생길 수 있다([CharacterMovement §4.1](../TechDesign_CharacterMovement.md)). 2인 PIE에서 `mover.debug.ShowCorrections 1`로 확인한다.

### Phase 3

- 사용자 플레이 테스트로 `IFrameDuration`·`JustDodgeWindow`·버프 수치를 1차로 확정한다. 군중(대부분 순수 엔티티)에 둘러싸인 상황에서 저스트 회피가 지나치게 쉬운지도 본다.
- 네트워크 에뮬레이션(`PktLag` 50/100ms)으로 게스트가 대시했을 때 판정 성공률과 체감을 기록한다. 결과에 따라 J-007(연출 예측 없음)과 J-010(RTT 역보정 없음)을 재검토한다. 대응 후보는 `design/Architecture.md` §6에 있다.
- 공통 문서 마감은 Phase 4로 옮겼다(2026-11-04, 사용자).

### Phase 4

- Phase 3 측정에서 지연이 있으면 넉백이 늦게 도착한 게스트 대시를 거부함을 확인했다(`design/Architecture.md` §6.1). 사용자 결정으로 피격 유예 버퍼(§6.2 A)를 구현한다. B(넉백 중 대시 허용)는 채택하지 않았다.
- 재측정은 Phase 3의 R2·R3와 같은 조건으로 한다(두 창 모두 `net.PktLag=25`·`50`, 검증 편성). 기준은 `AnalyzeDodgeLog.py`의 `dropped by server` 중 `press-then-hit`(Phase 3 유형)이다. 이미 맞은 뒤 누른 거부는 호스트도 잃는 경우라 기준에서 뺐다(2026-11-04).
- 위험: 게스트가 받는 모든 피해가 유예만큼 늦게 보인다. 경직 누적이 Worker Thread에서 Game Thread 보류 큐로 옮겨 가는 경로가 생긴다.
- Phase 3에서 옮겨 온 문서 마감을 이 Phase 끝에 한다.
  - `GameDesign_JustDodge.md`·`TechDesign_JustDodge.md`를 새로 만든다.
  - `TechDesign_ParrySystem.md`(Judge 순서), `TechDesign_HitDetection.md` §7.5(결과 enum), `TechDesign_CharacterMovement.md` §5(대시 무적)에 교차 링크를 넣는다.
  - 문서 인덱스 3곳(CLAUDE.md, ProjectOverview, Notion)과 `DevelopmentPlan.md`를 갱신한다.
- 결과(2026-11-05): 위 항목을 모두 했다. 교차 링크는 `TechDesign_Poise.md`(경직의 보류 경로)와 `TechDesign_Networking.md`(피격 유예)에도 넣었다. 상세는 `history/Phase04_Log.md`에 있다.

### 비주얼 트랙(V)

- 1차 단위는 그래픽스 진행과 상관없이 바로 시작한다. 단, 다음을 지킨다.
  - Niagara는 로컬 스페이스로 제자리에서 한 번 터지는 버스트만 쓰고, 힘 모듈을 끈다(`design/VisualDesign.md` §4). 월드 스페이스가 필요한 효과는 V3b로 미룬다.
  - 캐릭터 메시에 오버레이 머티리얼을 쓰지 않는다. 캐릭터 강조 채널(그래픽스 3-3)과 슬롯이 충돌할 수 있다.
  - 화면 연출은 임시로 구현하지 않는다(V5까지 미구현).
- 2차 단위를 시작하기 전에 [Graphics/Current.md](../Graphics/Current.md)에서 해당 게이트(단위 N·3-2·3-3)가 끝났는지 확인한다.
- 설계 원본은 `design/VisualDesign.md`다.

## 6. 범위 밖과 후속 아이디어

- 사운드: 사운드 에셋이 생기면 성공 큐의 `Sound` 필드에 연결한다.
- 버프 남은 시간 HUD 표시: 오라로 충분한지 V4b에서 판단한다.
- 적의 회피: 적이 판정 대상이 되려면 StateTree/GA에서 프래그먼트를 갱신하는 연결이 필요하다(패링과 같은 제약).
- 공중 대시: 의도된 제한이다.
- 저스트 회피 직후의 전용 반격 기술: 버프 외 보상을 추가하는 아이디어. 채택 전이면 `Idea_Backlog.md`로 보낸다.

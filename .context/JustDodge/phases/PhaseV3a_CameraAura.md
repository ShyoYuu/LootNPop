# V3a — 카메라·부착 버프 오라

> 상태: 구현·주요 검증 마감 — 미확인 경계는 아래에 명시 (2026-11-06)
> 선행: V1a·V2 주요 검증 정리. 미확인 경계는 각 실행서에 유지한다.

## 범위와 구현안

- 성공 큐에 전용 짧은 쉐이크를 연결한다. 기존 부모의 로컬 컨트롤러 검사로 성공한 본인 화면에서만 재생한다. FOV 변화는 쉐이크 패턴에 넣지 않는다.
- FOV 펀치는 `CR_ThirdPerson`의 FOV 설정 뒤 전용 Gameplay Cameras 노드에서 가산한다. 현행은 +3°·총 0.2초이며 사용자가 자연스럽다고 확인했다. 성공 큐 수신을 시작점으로 삼고 일반 대시에는 적용하지 않는다.
- **확정(J-024):** ADS 중 펀치를 생략하고 펀치 도중 ADS 진입 시 종료한다. 조준을 풀어도 이전 펀치는 재개하지 않는다.
- 오라는 기존 `.Buff` 지속 큐를 사용한다. 발밑·양손에 약한 무채색의 짧은 로컬 스페이스 버스트를 버프 동안 반복하고, 이동 꼬리·힘 모듈·메시 오버레이는 추가하지 않는다.
- `ALNPCharacterBase`는 `ACharacter`가 아닌 `APawn`이다. 엔진 기본 지속 큐는 `TargetAttachComponent`가 없으면 루트 캡슐에 붙으므로, 오라 큐에서 표시용 메시를 부착 대상으로 지정한다. 구체 부착점과 에셋 기본값은 라이브 에디터에서 확인한다.
- GE의 `bSuppressStackingCues=true`를 유지한다. 지속 큐의 기존 제거·재활용 경로를 사용해 갱신 중 중복 생성이나 만료 후 잔류를 막는다.
- 쉐이크 `CS_JustDodge` 현행은 위치·FOV 진폭 0, 회전 Pitch/Yaw/Roll 0.25°/0.15°/0.1°, 약 22~25Hz, 0.16초(진입 0.02·이탈 0.1초)다. 같은 쉐이크가 겹쳐 쌓이지 않게 한다.
- 오라 `NS_JustDodge_Aura`는 기존 사라짐 시스템을 복제해 두 로컬 스페이스 이미터를 조정했다. 현행은 0.3초 간격으로 검정 입자 6개(수명 0.45~0.65초)·흰색 입자 3개(0.45초)를 생성한다. 검정 크기 12×24~20×40cm·알파 0.75, 흰색 4×12~6×20cm·RGB 10·알파 0.6, 분포 반경 18cm다. 발밑 `root` 배율 1.6, `hand_l`·`hand_r` 배율 0.65다. 크기·알파 곡선을 유지하고, 이동은 로컬 +Z 12cm/s이며 힘 모듈은 꺼져 있다. 어두운 곳에서도 사용자가 괜찮다고 확인해 유지한다. 흰색 강조의 별도 인지는 보고받지 않았다.
- 발밑은 `NS_JustDodge_FootAura`로 분리했다. 검정 이미터만 전용 `M_JustDodge_FootSmoke`를 사용하며, 지형 근처에서 불투명도를 줄이는 DepthFade 기본 거리를 원본 120cm 대신 6cm로 줄였다. 사용자가 실시간으로 본 분위기·느낌·크기·모양과 어두운 곳의 시인성을 확인했다.

## 순서와 검증

1. ADS 정책 결정·라이브 에셋 조사 → 확인: 리그 노드 순서, 지속 큐 부모·기본값, 부착점.
2. 카메라 코드·오라 에셋 연결 → 확인: 전체 빌드 또는 적용 가능한 Live Coding, 대상 BP·Niagara·리그 컴파일과 저장.
3. 사용자 PIE → 확인: 본인만 쉐이크·FOV, ADS 전환, 호스트·게스트 양방향 오라, 연속 성공 시 유지·마지막 갱신 뒤 만료, 사망·리스폰 정리.
4. 결과·미확인 경계 기록 → V3a 단위를 마감하고 V4a 진행 여부를 사용자에게 확인한다.

## 미확인 경계와 다음 단위

- ADS 중 성공 큐 도착과 펀치 도중 ADS 진입의 정확한 경계는 별도 런타임 보고가 없다. 코드의 ADS 생략·시작 시각 폐기와 빌드는 확인했으며, V4a 지연 체감 확인에서 함께 볼 수 있다.
- 명시적 `LNP.Debug.JustDodgeTest resume` 콘솔 경로는 별도 실행 보고가 없다. 상단 Resume 재개는 사용자 확인을 받았다.
- 버프 중 사망은 콘솔로 정상 사망 경로를 실행한 범위에서 확인했다.
- 사용자 요청으로 V4a의 지연 중 순보 판독(V-05)·J-007 재검토 여부는 새 세션으로 넘기고, 이번 V3a와 인계 문서는 한 커밋으로 마감한다. V4a 실행서는 다음 세션 착수 때 작성한다. 임시 테스트 명령·미리보기는 유지하되 지연 판독은 미리보기 0의 실제 성공으로 검증한다.

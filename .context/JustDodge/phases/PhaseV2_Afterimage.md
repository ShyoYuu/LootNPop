# V2 — 고정 포즈 잔상

> 상태: 무기 교체·2인 양방향 출력 확인, 주요 검증 정리 — 수명 중 피격·넉백 경계는 미확인 (2026-11-05)
> 선행: V1a 주요 검증 및 게스트 방향 수정 재검증 통과

## 구현 규약

- 전용 액터를 만들지 않는다. 캐릭터가 소유하는 몸용 `UPoseableMeshComponent` 하나와 표시 중인 무기용 하나를 첫 사용 때 만들고 재사용한다.
- 루트·소켓에 부착하거나 Leader Pose로 연결하지 않는다. 성공 큐 수신 순간 `VisualMesh`·`WeaponMesh`의 포즈와 월드 배치를 복사하고 직접 뼈 변환을 갱신한다. 컴포넌트 Tick은 끈다.
- 순보로 원본을 숨기기 전에 복사한다. 기존 숨김 중 재진입은 현재 잔상을 덮어쓰지 않는다. 맨손이면 무기 잔상은 숨긴다.
- 새 `M_JustDodge_Afterimage`는 무채색 반투명·Unlit이며 몸체와 약한 흰색 프레넬을 사용한다. 몸·무기에 공유하는 MID의 `StartTime`을 성공 시 한 번 기록하고, 머티리얼 게임 시간으로 0.35초 페이드한다. 타이머가 끝나면 숨기고 다음 성공에 재사용한다.
- 충돌·물리·그림자·복제와 원본 오버레이는 사용하지 않는다. 캐릭터 종료 때 타이머를 정리한다. 본체 사망·파괴와 독립적인 잔상 수명은 보장하지 않는다.
- 기존 서버 확정 성공 큐 뒤에서 각 머신에 표시된 현재 포즈를 복사한다. 과거 포즈 복제나 연출 예측은 추가하지 않는다.

## 순서와 검증

1. 코드·머티리얼 작성 → 확인: 머티리얼 컴파일, Tick 없는 포즈 복사·미부착·수명 코드 검토.
2. 에디터 저장·종료 후 전체 빌드 → 확인: UHT·C++·링크 성공. 재시작 후 성공 큐에 머티리얼 연결·컴파일·대상 에셋만 저장.
3. 사용자 미리보기 평가 → 확인: 몸·장착 무기·맨손, 포즈·밝기·0.35초 페이드, 잔상이 원점 먼 실제 전투 위치에 출력.
4. 실제 성공 리슨 2인 → 확인: 양방향 표시·일반 대시 미재생·V1a 방향 유지. 무적 만료 뒤 넉백·물리 반응이 생겨도 잔상의 월드 배치와 포즈가 흔들리지 않는다.
